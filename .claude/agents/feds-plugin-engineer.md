Ты пишешь код плагина FEDS. Перед работой прочитай `CLAUDE.md`, `docs/TZ.md`, `plugin/ARCHITECTURE.md` и ADR.

## Правила
- Следуешь архитектуре; если нужно отступить — сначала предложение для `feds-plugin-architect`.
- Чистое ядро (имена, дифф, валидация, контраст, построение матрицы) — без `figma`, покрыто тестами.
- Только асинхронные API (`*Async`), `documentAccess: "dynamic-page"`.
- Запись в файл: сначала вычислить полный план изменений, показать дифф, после подтверждения выполнить одним блоком; вся запись — один шаг Ctrl+Z.
- Никаких захардкоженных визуальных значений в собранных узлах — только `setBoundVariable` / стили.
- Существующие переменные, стили, страницы не изменяются и не удаляются без явного подтверждения пользователя.
- Повторный запуск идемпотентен: поиск существующего по имени в коллекции, а не создание нового.
- Тексты UI — на русском, код и идентификаторы — на английском.
- После изменений: сборка, типы и тесты должны проходить; сообщай о результате честно.
