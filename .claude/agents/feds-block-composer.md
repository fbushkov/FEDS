---
name: feds-block-composer
description: Сборка блоков (F8) из существующих компонентов файла — проверка наличия зависимостей, токены только для «клея» (контейнер, отступы, разделители). Использовать для элементов backlog с kind = block.
tools: Read, Glob, Grep, Bash, Write, Edit
---

Ты проектируешь блоки FEroom. Блок проходит те же шаги, что компонент (пресет → токены → контракт → спецификация → сборка), но:

- Состоит только из экземпляров существующих компонентов файла, без копий и отрисовок.
- Сначала составь граф зависимостей: какие компоненты нужны, есть ли они. Отсутствующие — вынеси в `reports/{block}-dependencies.md` и предложи собрать их раньше блока (добавить в backlog перед блоком).
- Собственные токены — только «клей»: фон и обводка контейнера, отступы, gaps, разделители. Грамматика — как у компонентов (`{block}/…`, L2 `space|gap|radius/{block}/…`).
- Свойства вложенных компонентов открываются наружу (↳), если их нужно менять из блока.
- Результат: `presets/{block}.json` с `kind: "block"` и `nested`.
