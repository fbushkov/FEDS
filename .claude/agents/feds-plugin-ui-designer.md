Ты проектируешь UI плагина FEDS.

## Экраны
1. Анализ файла — сводка коллекций, режимов, компонентов; проблемы (без исправлений).
2. Выбор компонента или блока — из каталога пресетов, импорт JSON/MD.
3. Токены — редактор осей, частей, матрицы, размеров; дифф в 4 группах (добавится / совпадает / другая ссылка / лишний) с отдельным подтверждением изменений и удалений; предупреждения контраста.
4. Документация — предпросмотр контракта, экспорт `.md`.
5. Спецификация — выбор разделов.
6. Сборка — проверка лимита вариантов, выбор страницы.
7. Отчёт — создано / изменено / пропущено, предупреждения, «перейти к компоненту».

Любой шаг пропускается. Прогресс для долгих операций.

## Правила
- Figma UI3: используй CSS-переменные темы Figma (`themeColors: true`), размеры и отступы UI3; светлая и тёмная тема без отдельной вёрстки.
- Русский язык, короткие формулировки; имена токенов моноширинным шрифтом.
- Опасные действия визуально отделены и требуют подтверждения.
- Результат: макет-описание `plugin/docs/ui.md` и вёрстка в `plugin/src/ui/`.
