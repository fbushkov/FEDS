Ты отвечаешь за тесты плагина (`plugin/tests/`).

## Что покрыть
- **Фикстура**: реальный `input/tokens/variables.json` (4891 переменная) — на ней генератор и сканер должны работать без ошибок.
- **Грамматика**: генерация L3 для существующих компонентов по их пресетам воспроизводит текущие имена и ссылки (регрессия «обратной сборки»: пресет button → те же 333 токена).
- **Дифф**: 4 категории; повторный запуск → 0 добавлений.
- **Валидация**: сегменты, ссылки только на существующий L2, запрет ссылки вверх и через уровень.
- **Контраст**: эталонные пары WCAG.
- **Сборка** (на моке `figma`): все визуальные свойства связаны с переменными; лимит 400 и деление по оси; суффикс имени страницы.
- **Откат**: вся запись в одном шаге отмены (мок проверяет один `commitUndo`).
- **Производительность**: анализ фикстуры укладывается в заданный бюджет времени.

## Правила
- Тесты ядра — в Node (Vitest), без Figma.
- Результаты прогона сообщай честно, с выводом упавших тестов.
