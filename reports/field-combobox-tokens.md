## Решения и допущения

- Поле Combobox — текстовое поле (ввод, каретка, Focused без Pressed), поэтому цвета повторяют field/input один в один через свои L3 `field/combobox/*` (как field/select повторяет семантику Input). Состояния и инверсия — сегменты `inverse-*` в состоянии, как у field/input.
- Open отдельных токенов не получает: по select.md «Open может использовать ту же активную обводку, что и Focused» — используются `bg/focused` и `border/focused`. Признак Open меняет только направление Chevron.
- Фокус — акцентная обводка `border/focused`, как у Input (отдельного Focus Ring у field/input нет). Если автор решит показывать кольцо фокуса как у Select — добавить `field/combobox/focus-ring` → `color/static/focus/brand` и размеры `focus-border|focus-radius`.
- Размеры — свои L2 `*/field/combobox/*` (правило 3) со значениями оболочки Input: 32/40/48, отступы 6/8/10, скругление 6/8/10, иконки 16/20/24 в рамках 20/24/28. Скругление каретки — общий L2 семейства `radius/field/caret/{s}` (у Input он тоже общий).
- Chevron и Clear — экземпляры Icon Button (как `Select › Open-Close` и `Input › Clear`), своих цветов нет; рамка — `actions` 20/24/28, как у Input и Select. S = 20 меньше 24 px WCAG 2.5.8 — общий вопрос семейства (input.md, решение 5).
- Новое по сравнению с Input: `bg/selection` (подложка дописанной части в режиме List + inline, `color/static/bg/transparent/accent/brand/low`; прозрачный бренд работает в обеих темах, поэтому и `inverse-selection` ссылается на него же) и зазор поле–Dropdown `container-dropdown-gap` = 4 (как `gap/field/select/button-dropdown`).
- Dropdown — экземпляр `_ Select / Dropdown` (токены `field/select/dropdown/*` и дополнение из пресета field-dropdown: подсветка совпадения, Create, Empty/Loading). Своих токенов списка у Combobox нет.
- Типографика — свои L2 `typography/field/combobox/text/{s}/*` со значениями `typography/field/input/text` (14/20, 16/24, 18/28, Regular) и стили `typography/field/combobox/text/{s}`; Placeholder использует тот же стиль.
- Контраст, accepted: Placeholder (`color/static/text/base/soft`, 0.35) и обводка Default (`color/action/border/base/soft/default`, 0.15) ниже норм 4.5 и 3 — это общая семантика оболочки всего семейства (field/input, field/select). Замена только в одном поле сломала бы единообразие формы; вопрос вынесен автору для всего семейства сразу.
- Контраст, accepted: Warning (обводка `color/action/border/warning/calm/selected` и State Icon `color/static/indicator/warning/firm`) ниже 3 в light — как у field/input и field/select; состояние дублируется текстом Validation Message в Field. Кандидат на замену для всего семейства — `color/action/border/warning/firm/selected`.
- Контраст, accepted: текст Disabled — исключение WCAG 1.4.3 для неактивных элементов.
- Эффекты не нужны.
