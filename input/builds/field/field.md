# Field   
Field — обертка над полем ввода, которая объединяет **Label, Input / Text Area, Description, сообщение валидации, Counter** и служебные отступы в один элемент формы.   
Field отвечает за контекст и состояние поля, но не определяет поведение самого Input или Text Area.   
## Использовать   
- Когда полю нужен Label;   
- Когда требуется Description, сообщение Error / Warning / Success или Counter;   
- Для единообразного расположения полей в формах;   
- Когда нужно связать визуальное состояние контрола с поясняющим сообщением.   
   
## Не использовать   
|                                                                                                                 Задача |                                  Решение |
|:-----------------------------------------------------------------------------------------------------------------------|:-----------------------------------------|
|                                                                  Разместить контент, не относящийся к конкретному полю |                 Обычный layout-контейнер |
|                                                         Объединить несколько независимых контролов под одним названием |                  Группа полей / Fieldset |
|                                           Настроить ввод, Placeholder, Clear, Scroll, Resize и другие функции контрола |                        Input / Text Area |

## Состав   
|            Элемент |                                                                                                              Назначение |
|:-------------------|:------------------------------------------------------------------------------------------------------------------------|
|              Label |                                                                                 Название поля и дополнительный контекст |
|            Control |                                                                                                     Input или Text Area |
|        Description |                                                                                     Нейтральная подсказка или пояснение |
| Validation Message |                                                                                     Сообщение Error / Warning / Success |
|            Counter |                                                                       Количество введенных символов относительно лимита |
|      Extra Spacing |                                                          Опциональный служебный интервал между последовательными полями |

Не добавляйте элементы без необходимости: Field должен содержать только информацию, связанную с конкретным полем.   
   
## Ориентация   
Field поддерживает два варианта компоновки.   
|        Вариант |                                                                           Расположение |                                                                          Когда применять |
|:---------------|:---------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------|
|       Vertical |                                      Label над контролом, служебная информация под ним |                                               Основной вариант для форм и узких областей |
|     Horizontal |                                                            Label слева, контрол справа |                                          Формы с устойчивой сеткой и достаточной шириной |

В одной логической группе сохраняйте одинаковый принцип расположения полей.   
   
### Horizontal Field   
- Label и Control образуют две колонки;   
- Description, Counter и Validation Message относятся к Control и располагаются в его колонке;   
   
💡   
Расширенные варианты Label особенно полезны рядом с Text Area, где высота контрола позволяет разместить больше поясняющей информации.   
## Размеры   
Field поддерживает **S / M / L**.   
Размер Field должен соответствовать размеру вложенного контрола и определяет связанные с ним отступы и интервалы. Не комбинируйте, например, Label размера **S** с Control размера **L** и не меняйте внутренние gaps вручную.   
## Label   
Label должен кратко и однозначно называть поле. Поддерживаются следующие варианты:   
|                                 Вариант |                                                                               Когда использовать |
|:----------------------------------------|:-------------------------------------------------------------------------------------------------|
|                               Заголовок |                                                                                  Базовый вариант |
|                        Заголовок + `\*` |                                                                                Обязательное поле |
|                           кнопка-иконка |                                               Дополнительная контекстная информация или действие |
|                    дополнительный текст |                                                               Короткое уточнение назначения поля |
|                                  ссылка |                                                  Связанная справка или дополнительная информация |
|                                         |                                                                                                  |

### Акцент Label   
В спецификации предусмотрены **акцентный** и **приглушенный** варианты заголовка. Используйте их последовательно в соответствии с визуальной иерархией формы, а не для обозначения состояния валидации.   
### Обязательное поле   
Маркер `\*` визуально показывает обязательность поля.   
- Используйте его последовательно во всей форме;   
- Обязательность должна быть задана также программно через *required* или эквивалентную семантику;   
- Не используйте только цвет для обозначения обязательности.   
   
## Description   
Description дополняет Label информацией, которая помогает заполнить поле, но не является частью его названия. Поддерживаются варианты:   
|                           Вариант |                                                                               Назначение |
|:----------------------------------|:-----------------------------------------------------------------------------------------|
|                         Подсказка |                                                                       Короткое пояснение |
|                Подсказка + иконка |                                           Пояснение с дополнительным визуальным маркером |
|               Подсказка + Counter |                                             Пояснение и информация о количестве символов |

Description должна быть полезной до возникновения ошибки. Не дублируйте в ней Label или Validation Message.   
   
## Counter   
Counter относится к Field, а не к Input или Text Area. Поддерживаются три состояния:   
|          Состояние |                                                                                              Поведение |
|:-------------------|:-------------------------------------------------------------------------------------------------------|
|             Hidden |                                                                                Счетчик не отображается |
|            Regular |                                                        Показывает текущее значение относительно лимита |
|         Over Limit |                                                  Показывает превышение допустимого количества символов |

По спецификации Counter может быть скрыт по умолчанию и появляться после начала ввода или при достижении заданного порога *N*. Порог определяется сценарием. Место под Counter рекомендуется предусматривать заранее, чтобы появление счетчика не смещало соседний контент. Counter отображается полностью и не обрезается многоточием.   
## Состояния Field   
Field не дублирует интерактивные состояния контрола (*Hover*, *Focused*, *Disabled*, *Read Only*). Для Field используются состояния, связанные с результатом проверки значения.   
|          Состояние |                                                                                                                   Назначение |
|:-------------------|:-----------------------------------------------------------------------------------------------------------------------------|
|               Base |                                                                                          Нет сообщения о результате проверки |
|              Error |                                                                                       Пользователь должен исправить значение |
|            Warning |                                                                    Значение требует внимания, но может оставаться допустимым |
|            Success |                                                            Проверка завершилась успешно и подтверждение полезно пользователю |

### Validation Message   
- Формулируйте сообщение кратко и конкретно;   
- Error должен объяснять, что требуется исправить;   
- Не используйте цвет как единственный способ передать смысл состояния;   
- Не дублируйте одно сообщение одновременно в Description и Validation Message.   
   
## Длинный текст   
Field ограничивает длину служебных текстов, чтобы сохранять предсказуемую высоту и сетку формы.   
|                                                       Элемент |                                                                      Правило |
|:--------------------------------------------------------------|:-----------------------------------------------------------------------------|
|                                        Label в Vertical Field |                                                                  До 1 строки |
|                                      Label в Horizontal Field |                                                                   До 2 строк |
|                                                   Description |                                                                   До 2 строк |
|              Расширенный Label в Horizontal Field с Text Area |                                    До 4 строк суммарной служебной информации |
|                                                       Counter |                                                Всегда отображается полностью |

Если доступное пространство закончилось, текст обрезается с `…`, а полная версия показывается через Tooltip.   
## Дополнительная информация в Label   
Кнопка-иконка, дополнительный текст и ссылка используются только для информации, непосредственно связанной с полем.   
- Не превращайте Label в отдельный информационный блок;   
- Оставляйте одно основное название поля;   
- Ссылка должна вести на связанную справку или действие;   
- Кнопка-иконка должна иметь понятное доступное имя;   
- Критически важные инструкции не прячьте только в Tooltip.   
   
## Extra Spacing   
**Extra Spacing** — служебная область в нижней части Field, которая создает дополнительный вертикальный интервал между последовательными полями.   
- Не содержит контента;   
- Является опциональной;   
- Используется только когда стандартного интервала между Field недостаточно;   
- Не добавляйте Extra Spacing одновременно с эквивалентным внешним *gap*, чтобы не получать двойной отступ.   
   
## Regular и Inverse   
Field поддерживает два цветовых режима:   
|      Режим |                                                   Где применять |
|:-----------|:----------------------------------------------------------------|
|    Regular |                               Светлые и стандартные поверхности |
|    Inverse |                                              Темные поверхности |

Label, Description, Validation Message, Counter и вложенный Control должны использовать один режим внутри одного Field.   
## Доступность (A11y)   
- Каждый Control должен быть программно связан со своим Label через  / *for* или *aria-labelledby*;   
- Description связывайте с контролом через *aria-describedby*;   
- Для Error используйте *aria-invalid="true"* и связывайте сообщение через *aria-describedby* или *aria-errormessage*;   
- Для обязательного нативного поля используйте *required*; для кастомных контролов — соответствующую ARIA-семантику;   
- Значение маркера должно быть понятно пользователю и не должно быть единственным программным признаком обязательности;   
- Интерактивные элементы внутри Label должны быть доступны с клавиатуры и иметь доступное имя;   
- Tooltip с полным текстом должен открываться также по фокусу;   
- Сам контейнер Field не должен создавать дополнительную остановку Tab: фокус получают Control и интерактивные элементы внутри него.   
   
## Делать   
- Использовать Field как единую оболочку для названия, пояснений и состояния поля;   
- Выбирать одну ориентацию для логически связанной группы;   
- Сохранять краткий и понятный Label;   
- Связывать Validation Message с соответствующим состоянием Control;   
- Показывать Counter только когда информация о лимите действительно полезна;   
- Использовать системные размеры, gaps и Extra Spacing вместо ручных отступов.   
   
## Не делать   
- Не использовать Placeholder вместо Label;   
- Не перегружать Label несколькими действиями и длинными пояснениями;   
- Не дублировать один и тот же текст в Label, Description и Validation Message;   
- Не обозначать Error, Warning, Success или обязательность только цветом;   
- Не использовать Field как универсальный контейнер для произвольного контента.   
   
## Связанные компоненты   
|          Компонент |                                                                               Роль |
|:-------------------|:-----------------------------------------------------------------------------------|
|              Input |                                                  Однострочный Control внутри Field |
|          Text Area |                                                 Многострочный Control внутри Field |
|            Tooltip |                                        Полная версия обрезанного служебного текста |
|        Icon Button |                                     Дополнительное действие или информация в Label |
| Search Input, Password Input, Number Input | Однострочные Control внутри Field *(добавлено docs-writer 19.09.2026)* |
| Select, Combobox, Multiselect | Control выбора внутри Field *(добавлено docs-writer 19.09.2026)* |

## Field в Figma и в токенах   
*(добавлено docs-writer 19.09.2026)*   
- Field — служебная обёртка, а не публикуемый компонент. В Figma это локальный компонент `_Field` (префикс `_` исключает публикацию) со слотом Control (Instance swap);   
- В библиотеке публикуются готовые сборки: Input Field, Search Field, Password Field, Number Field, Text Area Field, Select Field, Combobox Field, Multiselect Field;   
- Размер и состояние валидации в сборке задаются одним свойством для Field и Control, чтобы они не расходились;   
- Токены Field — одна группа уровня 3 `field/*`, общая для всех контролов;   
- Подробно — `docs/forms-architecture.md`.
