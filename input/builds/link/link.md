# Link

# Inline Link

Текстовая ссылка внутри предложения или абзаца. Компонент не используется самостоятельно: он всегда является частью окружающего текста и ведет пользователя к связанной информации, другой странице, документу, разделу или внешнему ресурсу.

В обычном состоянии Inline Link должна быть подчеркнута, чтобы пользователь мог легко отличить ссылку от обычного текста. Для inline-ссылки используется та же типографика, что и для окружающего текста.

**Главное отличие от Standalone Link**: Inline Link встроена в текст и должна быть визуально распознаваема даже без наведения. Если ссылка стоит отдельно в таблице, списке, меню или каталоге – используйте Standalone Link.

## Использовать

* Ссылка внутри предложения, короткой фразы;
* Переход к связанной информации;
* Ссылка на инструкцию, статью, документ, справку;
* Ссылка внутри уведомления, подсказки, описания поля.

## Не использовать

* Если ссылка стоит отдельно, то используйте Standalone Link;
* Если нужно выполнить действие, то используйте Button;
* Если ссылка выглядит как фильтр или выбранное значение, то используйте Chip;
* Если нужно переключить раздел, то используйте Tabs;
* Если вся карточка кликабельна, не дублируйте внутри нее inline-ссылки.

## Тип

| Тип | Когда применять |
|----|----|
| Main / Blue | Основной вариант для навигации и справочных переходов |
| Danger / Red | Деструктивные или рискованные переходы: удалить, отменить, отозвать |
| Secondary / Grey | Второстепенные ссылки |

## Размер

Inline Link наследует типографику окружающего текста. Размер компонента нужен для систематизации состояний и токенов, но не должен выбиваться из текстового блока.

| Размер | Где применять |
|----|----|
| XL | Крупные промо-блоки, hero-тексты, большие информационные страницы |
| L | Описания в формах, пустые состояния, крупные карточки |
| M | Стандартный размер текста в интерфейсе |
| S | Плотные интерфейсы, таблицы, подписи, вспомогательные тексты |

## Ограничения

* Рекомендуемая длина: 1–4 слова;
* Для длинных названий допускается обрезка с многоточием;
* При обрезке полный текст показывается в tooltip;
* Не используйте слишком короткий текст без смысла: "тут", "здесь", "сюда";
* Текст ссылки должен описывать, куда пользователь перейдет.

## Состояние

| Состояние | Когда применяется | Поведение |
|----|----|----|
| Default | Ссылка доступна для перехода | Цвет по типу, текст подчеркнут |
| Hover | Курсор над ссылкой | Цвет становится активнее, подчеркивание сохраняется, возможен tooltip |
| Pressed | Момент нажатия | Цвет темнее/контрастнее, подчеркивание сохраняется |
| Visited | Пользователь уже переходил по ссылке | Цвет становится менее активным или светлее |
| Disabled | Переход недоступен | Ссылка становится обычным текстом, без клика |
| Focused | Навигация с клавиатуры | Видимый focus ring вокруг ссылки |

## Делать

* Использовать тот же размер и стиль текста, что у окружающего текста;
* Давать ссылке понятное название;
* Использовать tooltip для длинных или обрезанных ссылок.

## Не делать

* Не использовать Inline Link отдельно от текста;
* Не смешивать разные размеры ссылок внутри одного абзаца;
* Не использовать красный цвет для обычной справочной ссылки.

## Доступность (A11y)

* Focus Ring при навигации с клавиатуры;
* Поддержка Enter и Space для активации;
* Если используется tooltip, он должен быть связан со ссылкой через aria-describedby.

## Адаптив

* На мобильных устройствах для ссылок размера S используйте более длинные текстовые формулировки (для удобства нажатия);
* Длинные ссылки должны переноситься по строкам без поломки верстки;
* На мобильных устройствах не  используется tooltip.

## Связанные компоненты

* **Standalone Link** – для самостоятельных ссылок вне текста;
* **Button** – для действий;
* **Chip** – для фильтров, тегов и выбранных значений.

# **Standalone Link**

Самостоятельная текстовая ссылка, которая не встроена в абзац или предложение. Используется как отдельный интерактивный элемент в таблицах, списках, каталогах, карточках, навигационных группах и других интерфейсных блоках.

**Главное отличие от Inline Link**: Standalone Link существует отдельно от основного текста. Если ссылка находится внутри предложения – используйте Inline Link.

## **Использовать**

* Действие, которое является переходом, а не операцией (открытие другого URL);
* Переход к деталям объекта. Ссылка в: карточке, таблице, списке или каталоге;
* Переход к файлу, документу или разделу страницы;
* Группа ссылок в навигационном блоке.

## **Не использовать**

* Если ссылка встроена в предложение, то используйте Inline Link;
* Если нужно выполнить действие, то используйте Button;
* Если нужно выбрать фильтр, то используйте Chip;
* Если нужно переключить вкладку, то используйте Tabs.

## **Вариант**

| **Вариант** | **Назначение** | **Пример** |
|----|----|----|
| Only Text | Только текстовая ссылка | "Настройка" |
| Icon + Text | Иконка слева усиливает смысл | "Открыть в новой вкладке" |
| Text + Icon | Иконка справа показывает направление или внешний переход | "Правила использования ↗" |
| Both Icons | Иконки с двух сторон для сложных сценариев | "Документ ↗" |

## **Тип**

| **Тип** | **Назначение** |
|----|----|
| Main / Blue | Основная ссылка |
| Danger / Red | Опасная или деструктивная ссылка |
| Secondary / Grey | Второстепенная ссылка |

## **Размер**

| **Размер** | **Где применять** |
|----|----|
| XL | Крупные навигационные блоки, промо-страницы, пустые состояния |
| L | Карточки, списки, крупные формы |
| M | Стандартный размер для большинства интерфейсов |
| S | Таблицы, плотные списки, вспомогательные действия |

## **Ограничение**

* Рекомендуемая длина: до 3 слов;
* Максимальная длина зависит от контейнера;
* При нехватке места используется обрезка с многоточием;
* Полный текст показывается в tooltip.

## **Состояние**

| **Состояние** | **Когда применяется** | **Поведение** |
|----|----|----|
| Default | Ссылка доступна для перехода | Цвет по типу, без подчеркивания |
| Hover | Курсор над ссылкой | Появляется подчеркивание |
| Pressed | Момент нажатия | Цвет темнее/контрастнее, подчеркивание сохраняется |
| Disabled | Переход недоступен | Ссылка становится неактивной, цвет приглушен |
| Focused | Навигация с клавиатуры | Видимый focus ring вокруг ссылки |

## **Группа ссылок**

* Standalone Links могут использоваться в группе, если это набор переходов:
* Все ссылки в группе одного размера;
* Отступы между ссылками одинаковые;
* Ссылки имеют общий контекст;
* Типы Main, Danger и Secondary не смешиваются в одной группе.

## **Доступность (A11y)**

* Focus Ring при навигации с клавиатуры;
* Поддержка Enter и Space для активации;
* Для внешних ссылок желательно указывать, что ссылка ведет на внешний ресурс;
* Disabled-ссылка не должна попадать в Tab-навигацию;
* Если используется tooltip, он должен быть связан со ссылкой через aria-describedby.

## **Адаптив**

* Длинные ссылки должны обрезаться или переноситься по правилам контейнера;
* На мобильных устройствах размер S не используется из-за маленькой области нажатия;
* На мобильных устройствах используется вертикальная компоновка групп ссылок;
* На мобильных устройствах, не  используется tooltip.

## **Связанные компоненты**

* **Inline Link** – для ссылок внутри текста;
* **Button** – для действий.
