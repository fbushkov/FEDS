# Text Area   
Text Area — многострочное поле для ввода и редактирования длинного текста: комментария, описания, сообщения.   
Наследует оболочку Input (`input.md`, раздел «Оболочка поля (база семейства)»). Отличия — многострочное Content, высота по числу строк, auto-grow, Resize и внутренняя прокрутка; Enter переносит строку, а не отправляет форму.   
Label, Description, сообщения и Counter относятся к Field.   
## Использовать   
- Для текста длиннее одной строки;   
- Когда длина текста заранее неизвестна: комментарий, описание задачи, причина отказа;   
- Когда пользователю важно видеть и править весь текст сразу.   
   
## Не использовать   
|                                                                              **Задача** |                             **Компонент** |
|:----------------------------------------------------------------------------------------|:------------------------------------------|
|                                                    Короткое однострочное значение |                                     Input |
|                                      Текст с форматированием, упоминаниями, списками |                  Rich Text Editor (отдельный проект) |
|                                                        Поиск по запросу |                              Search Input |

## Состав   
|             **Часть** |                                                                **Отличие от Input** |
|:----------------------|:------------------------------------------------------------------------------------|
|             Контейнер |                       Высота зависит от числа строк; фон, обводка и состояния — как у Input |
|  Placeholder / Value |                            Многострочные; текст переносится по словам |
|  State Icon / Spinner |                                               Закреплены в правом верхнем углу |
|         Resize Handle |                                    Правый нижний угол, только если Resize включён |
|           Scroll Bar |                                     Появляется, когда текст выше максимальной высоты |

Leading Zone, Prefix, Suffix, Clear и Actions не используются: для длинного текста они сокращают место и отвлекают. Counter — часть Field, а не Text Area.   
## Размеры   
|       **Размер** |                                                                         **Где применять** |
|:-----------------|:------------------------------------------------------------------------------------------|
|                S |                                        Комментарии в таблицах и плотных панелях |
|                M |                                                   Стандартный размер для форм |
|                L |                                        Крупные формы, основной текст шага мастера |

Размер задаёт отступы и типографику, как у Input того же размера. Высоту задаёт число строк.   
## Высота и строки   
|         **Настройка** |                                               **Значение по умолчанию** |                                                          **Поведение** |
|:----------------------|:---------------------------------------------------------------------------|:-------------------------------------------------------------------------|
|              Min rows |                                                  3 строки |                               Высота пустого поля |
|              Max rows |                                                  8 строк |                   Предел auto-grow; дальше включается прокрутка |
|             Auto-grow |                                                  Включён |              Поле растёт с каждой новой строкой от Min до Max rows |
|                Resize |                                    None при Auto-grow, Vertical без него |                             Пользователь тянет поле за правый нижний угол |

- Высота = число строк × высота строки + вертикальные отступы. Строку задаёт типографика размера, отступы — уровень 2;   
- Изменение размера по горизонтали не используется: оно ломает сетку формы;   
- При Resize = Vertical поле нельзя сделать ниже Min rows;   
- Auto-grow не уменьшает поле ниже Min rows после удаления текста.   

## Прокрутка   
- Когда текст выше Max rows, прокручивается содержимое, а не контейнер: обводка, отступы и State Icon остаются на месте;   
- При вводе каретка всегда видна: поле прокручивается к ней;   
- Скроллбар не перекрывает текст и State Icon;   
- В Read Only и Disabled прокрутка доступна, чтобы прочитать текст целиком.   

## Содержимое   
Правила Placeholder — как у Input. Placeholder может занимать несколько строк, но не должен содержать требований: их место в Description.   
- Длинные слова и ссылки переносятся, а не выходят за границу поля;   
- Пустые строки и переносы, введённые пользователем, сохраняются.   

### Counter через Field   
- Лимит символов показывает Counter в Field (состояния Hidden, Regular, Over Limit — `field.md`);   
- Не обрезайте ввод по лимиту молча (`maxlength`): текст, вставленный целиком, потеряет конец без предупреждения. Разрешите ввести больше, покажите Over Limit и Error при отправке (так же делает GOV.UK Character count);   
- Место под Counter предусматривайте заранее, чтобы форма не прыгала.   

## Состояния   
Состояния — как у оболочки Input: Default, Hover, Focused, Disabled, Read Only, Error, Warning, Success, Loading.   
|        **Состояние** |                                                                   **Отличие** |
|:---------------------|:------------------------------------------------------------------------------|
|             Disabled |                                         Resize недоступен; прокрутка мышью допустима |
|            Read Only |                          Resize недоступен; текст выделяется и прокручивается |
|    Error / Warning / Success |                                      State Icon в правом верхнем углу |
|              Loading |                                     Spinner в правом верхнем углу |

## Валидация   
- Error — обязательный текст не заполнен или превышен лимит;   
- Текст сообщения называет, что исправить: «Сократите текст на 24 символа», а не «Слишком длинно»;   
- Проверяйте после ухода из поля или при отправке, а не на каждый символ.   

## Regular и Inverse   
|      **Режим** |                                               **Где применять** |
|:---------------|:----------------------------------------------------------------|
|        Regular |                               Светлые и стандартные поверхности |
|        Inverse |                                              Темные поверхности |

## Доступность (A11y)   
- Используйте нативный `<textarea>`;   
- Имя, Description и сообщения — через Field (`label`, `aria-describedby`, `aria-invalid`);   
- Counter связывайте через `aria-describedby`. Об изменении числа символов сообщайте через live-region с задержкой, а не на каждый символ, иначе screen reader перебивает ввод;   
- Resize Handle — нативная возможность поля; не делайте его единственным способом увидеть весь текст: прокрутка обязательна;   
- Tab не вставляет символ табуляции, а переводит фокус дальше: иначе пользователь клавиатуры не выйдет из поля (WCAG 2.2, критерий 2.1.2).   

## Управление клавиатурой   
|          **Действие** |                                                                                  **Результат** |
|:----------------------|:-----------------------------------------------------------------------------------------------|
|                   Tab |                                                 Переводит фокус в поле и дальше, не вставляет табуляцию |
|           Shift + Tab |                                                                         Перемещает фокус назад |
|                 Enter |                                                                                Новая строка |
|      Ctrl/Cmd + Enter |                               Отправляет форму — только если сценарий это объявляет (комментарии, чат) |
|    Стрелки, Home / End |                                           Перемещают каретку по строкам и внутри строки |
|  Ctrl/Cmd + Home / End |                                                    Переходят в начало / конец текста |
|   Page Up / Page Down |                                                    Прокручивают текст внутри поля |

## Делать   
- Задавать Min rows по ожидаемой длине текста;   
- Ограничивать рост через Max rows и прокрутку;   
- Показывать лимит через Counter в Field;   
- Сохранять переносы строк пользователя.   

## Не делать   
- Не использовать Text Area для короткого значения;   
- Не разрешать изменение размера по горизонтали;   
- Не обрезать текст по лимиту молча;   
- Не отправлять форму по Enter;   
- Не добавлять в поле Clear и Actions.   

## Связанные компоненты

|:-----------------------|:------------------------------------------------------------------|
|                  Input |                                Базовая оболочка; короткое однострочное значение |
|                  Field |                              Label, Description, Counter, сообщения |
|       Rich Text Editor |                          Текст с форматированием (отдельный проект) |

## Решения для согласования   
*(docs-writer 19.09.2026)*   
1. **Отдельный компонент:** другая анатомия (многострочность, Resize, прокрутка) и другая клавиатура (Enter — новая строка).   
2. **Min rows = 3, Max rows = 8, Auto-grow включён по умолчанию.** Числа — наше предложение, в исходных документах их нет.   
3. **Resize: None при Auto-grow, Vertical без него;** горизонтального нет.   
4. **Leading Zone, Suffix, Clear и Actions не используются;** State Icon и Spinner — в правом верхнем углу.   
5. **Лимит не обрезает ввод,** превышение показывает Counter Over Limit и Error при отправке.   
6. **Ctrl/Cmd + Enter отправляет форму** только в сценариях, где это объявлено.   
7. **Название:** в документах пользователя встречаются «Textarea» и «Text Area»; предлагаем «Text Area», как в `field.md` и каталоге.
