# Number Input   
Number Input — однострочное поле для числового значения, которое можно ввести с клавиатуры и изменить с заданным шагом.   
Наследует оболочку Input (`input.md`, раздел «Оболочка поля (база семейства)»). Отличия — клавиатурная модель spinbutton (стрелки меняют значение), границы min / max, шаг и форматирование числа.   
Документ описывает три варианта одного компонента:   
|        **Вариант** |                                                                         **Что добавляет** |
|:-------------------|:------------------------------------------------------------------------------------------|
|             Number |                                               Число с шагом и границами, без кнопок |
|            Stepper |                                                  Number + кнопки − / + в Trailing Zone |
|           Currency |                            Number + символ валюты и фиксированное число знаков после запятой |

Label, Description с допустимым диапазоном и сообщения относятся к Field.   
## Использовать   
- Для количества, процента, длительности, суммы и других величин, с которыми выполняют арифметику;   
- **Stepper** — когда значение чаще меняют на небольшой шаг, чем вводят: количество товара, число гостей;   
- **Currency** — для денежной суммы.   
   
## Не использовать   
|                                                                                   **Задача** |                                            **Компонент** |
|:---------------------------------------------------------------------------------------------|:---------------------------------------------------------|
|                            Номер телефона, ИНН, номер договора, код — «число», которое не считают |         Input, `inputmode="numeric"` (`input.md`, «Типы значения») |
|                                              Выбрать значение из нескольких фиксированных |                            Select / Segmented Control |
|                                           Примерное значение в диапазоне, точность не важна |                                          Slider (позже) |
|                                                                       Дата или время |                                        Date Picker (позже) |

## Конфигурация   
|      **Зона** |                                                  **Содержимое** |                                                    **Отличие от Input** |
|:--------------|:----------------------------------------------------------------|:------------------------------------------------------------------------|
|  Leading Zone |                        Icon; у Currency — символ валюты как Prefix |                                                     Как у Input |
|       Content |                                         Placeholder или Value (число) |                                         Форматирование числа по локали |
| Trailing Zone | Suffix (единица измерения или валюта), − / + (Stepper), State Icon / Spinner | − и + стоят на месте Actions; Clear не используется |

Порядок в Trailing Zone: **Suffix → Decrement (−) → Increment (+) → State Icon / Spinner**. Кнопки − / + — экземпляры Icon Button того же размера, что Clear у Input.   
## Размеры   
|       **Размер** |                                                                         **Где применять** |
|:-----------------|:------------------------------------------------------------------------------------------|
|                S |                                        Таблицы, корзины, плотные панели |
|                M |                                                   Стандартный размер для форм |
|                L |                                        Крупные формы, основное значение шага мастера |

Высоты и отступы — как у Input того же размера.   
## Содержимое   
### Значение и формат   
- Разделитель групп разрядов и десятичный разделитель берутся из локали: для русского языка это `1 000 000,5`;   
- При вводе поле принимает и точку, и запятую как десятичный разделитель;   
- Форматирование с разделителями разрядов применяется после ухода из поля; во время ввода значение не переформатируется, чтобы не прыгала каретка;   
- Лишние нули и пробелы после ухода из поля убираются.   

### Min, max и шаг   
- Допустимый диапазон пишите в Description: «От 1 до 99»;   
- Кнопка − недоступна на минимуме, + — на максимуме;   
- Значение вне диапазона, введённое вручную, не исправляется молча: поле показывает Error с диапазоном;   
- Шаг задаётся сценарием (1, 0,5, 100). Ручной ввод не обязан попадать в шаг, если сценарий этого не требует.   

### Currency   
- Символ валюты — Prefix или Suffix по правилам локали: `1 000,00 ₽`, `$1,000.00`. Пользователь его не вводит;   
- Число знаков после запятой фиксировано для валюты и дополняется после ухода из поля: `1 000` → `1 000,00`;   
- Отрицательные суммы разрешайте, только если они есть в сценарии.   

### Выравнивание   
В форме значение выравнивается по левому краю, как у Input. В колонке таблицы — по правому, чтобы разряды стояли друг под другом.   
## Состояния   
Состояния — как у оболочки Input.   
|        **Состояние** |                                                                   **Отличие** |
|:---------------------|:------------------------------------------------------------------------------|
|   Default на границе |                              − (на min) или + (на max) в состоянии Disabled |
|             Disabled |                                              Кнопки − / + не показываются |
|            Read Only |                    Кнопки − / + не показываются; стрелки не меняют значение |
|                Error |                                                    Значение вне диапазона или не число |

## Валидация   
- Error — значение не число, вне диапазона или обязательное значение не заполнено;   
- Сообщение называет допустимое: «Введите число от 1 до 99», а не «Неверное значение»;   
- Warning — значение допустимо, но необычно: например, количество больше остатка на складе;   
- Проверяйте после ухода из поля, а не на каждый символ: промежуточное значение `1,` или `-` не является ошибкой.   

## Regular и Inverse   
|      **Режим** |                                               **Где применять** |
|:---------------|:----------------------------------------------------------------|
|        Regular |                               Светлые и стандартные поверхности |
|        Inverse |                                              Темные поверхности |

## Доступность (A11y)   
- Используйте роль `spinbutton` по паттерну WAI-ARIA APG: `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, а для отформатированного значения — `aria-valuetext` («1 000 рублей»);   
- Не используйте нативный `type="number"`: он меняет значение колесом мыши, принимает `e` и по-разному обрабатывает десятичный разделитель в разных браузерах. Используйте `type="text"` с `inputmode="decimal"` или `inputmode="numeric"`;   
- Кнопки − / + — кнопки с доступными именами «Уменьшить» / «Увеличить». Как в примере APG, они не входят в последовательность Tab: с клавиатуры значение меняют стрелки;   
- Символ валюты и единица измерения должны входить в доступное описание, если без них значение можно понять неверно (`input.md`, «Доступность»);   
- Кнопки − / + должны иметь область нажатия не меньше 24 × 24 px (WCAG 2.2, критерий 2.5.8).   

## Управление клавиатурой   
|          **Действие** |                                                                                  **Результат** |
|:----------------------|:-----------------------------------------------------------------------------------------------|
|                   Tab |                                     Переводит фокус в поле; кнопки − / + пропускаются |
|           Shift + Tab |                                                                         Перемещает фокус назад |
|                 ↑ / ↓ |                                                    Увеличивает / уменьшает значение на шаг |
|   Page Up / Page Down |                                                Увеличивает / уменьшает на крупный шаг (если задан) |
|            Home / End |                                               Устанавливает min / max (если заданы) |
|         ← / →, Backspace, Delete |                                                  Перемещают каретку и редактируют текст |
|          Enter в поле |                                                                                  Отправляет форму |

💡   
Home и End в spinbutton меняют значение, а не двигают каретку, — это модель APG. Именно поэтому Number Input — отдельный компонент, а не настройка Input.   
## Делать   
- Показывать диапазон в Description;   
- Блокировать − и + на границах;   
- Форматировать число по локали после ухода из поля;   
- Выбирать Stepper, когда значение меняют малыми шагами.   

## Не делать   
- Не использовать Number Input для телефонов, кодов и идентификаторов;   
- Не исправлять значение вне диапазона молча;   
- Не переформатировать значение на каждый символ;   
- Не менять значение прокруткой колеса мыши;   
- Не делать кнопки − / + меньше области нажатия Clear.

## Решения для согласования   
*(docs-writer 19.09.2026)*   
1. **Number, Stepper и Currency — один компонент с вариантами,** а не три: анатомия отличается только наличием кнопок и символа валюты, клавиатурная модель одна.   
2. **Кнопки − / + в Trailing Zone** на месте Actions, перед State Icon: State Icon остаётся крайней системной позицией, как у Input. Альтернатива — − слева и + справа от значения.   
3. **Кнопки − / + не входят в Tab-последовательность**, как в примере APG; с клавиатуры значение меняют стрелки.   
4. **Форматирование — после ухода из поля,** ввод принимает и точку, и запятую.   
5. **Значение вне диапазона не исправляется автоматически,** а даёт Error с диапазоном.   
6. **Выравнивание:** по левому краю в форме, по правому в таблице.   
7. **Нативный `type="number"` не используется.**
