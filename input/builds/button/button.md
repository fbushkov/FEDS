# Button

Кнопка инициирует действие пользователя. Это самый частый интерактивный элемент — критично использовать ее последовательно по всему продукту, чтобы пользователь понимал приоритет и тип действия.

## **Использовать**

* Действие, которое запускает процесс;
* Подтверждение или отмена;
* Открытие модального окна, панели, нового экрана.

## **Не использовать**

* Если нужна навигация, то используйте Tabs или Link;
* Если переключаете состояние (on/off), то используйте Toggle;
* Если выбираете один из вариантов, то используйте Tabs или Segmented Control;
* Если одиночный или множественный выбор, то используйте Checkbox или Chip;
* Если нужно перейти внутрь раздела/списка/таблицы, то используется Link.

## Тип

| Вид | Когда применять | Сколько на экране |
|----|----|----|
| Fill | Главное действие | 1 раз на смысловой блок |
| Outline | Важное, но не главное действие | 2-3 |
| Text | Второстепенные действия | без ограничений |


:::warning
В одном смысловом контексте (форма, модалка, карточка) используйте только одну Fill-кнопку с Primary типом. Иначе пользователь не поймет, что главное.

:::

## Цвет

Цвет кнопки несет смысл, выбирай по семантике, а не по эстетике:

| Тип | Назначение | Пример |
|----|----|----|
| Primary | Главное позитивное действие | "Сохранить", "Создать" |
| Primary Soft | Важное действие, для насыщенных интерфейсов | "Применить фильтр" |
| Secondary | Альтернатива основному действию | "Отмена", "Назад" |
| Ghost | Дополнительное действие | "Очистить", "Сбросить" |
| Danger | Необратимое действие | "Удалить навсегда" |
| Danger Soft | Деструктивное действие | "Архивировать" |

## Размер

| Размер | Где применять |
|----|----|
| XL | Лендинги, hero-блоки, главный CTA на пустом экране |
| L | Большие интерфейсы, формы регистрации, модальные окна |
| M | Стандартный размер: формы, тулбары, карточки |
| S | Плотные интерфейсы: таблицы, тулбары, фильтры |


:::warning
Не смешивайте кнопки разных размеров в одной группе. Все кнопки, на одной "строке действий", должны быть одного размера.

:::

## **Содержимое**

* **Только текст**. Стандартный случай. Глагол в инфинитиве, до 3 слов: "Сохранить", "Создать задачу";
* **Текст + иконка слева**. Для усиления смысла или или категории действия: "+ Добавить",  "Скачать";
* **Текст + иконка справа**. Для указания направления, продолжения, раскрытия: "Далее", "Меню";
* **Только иконка**. Для плотных интерфейсов, тулбаров. **Обязательно** нужно добавлять tooltip и aria-label.

## Делать

* Глагол + объект: "Создать задачу", "Удалить файл";
* Конкретно: "Сохранить изменения" вместо "ОК";
* В кнопках подтверждения действие нужно дублировать: "‎Удалить" или "Удалить задачу", а не "ОК".

## Не делать

* "ОК", "Готово", "Отправить" в отрыве от контекста;
* Длинные фразы и предложения;
* Эмодзи и капс;

## Состояние

| Состояние | Когда применяется | Поведение |
|----|----|----|
| Default | Кнопка готова к нажатию | — |
| Hover | Курсор над кнопкой | Подсветка |
| Pressed | Момент клика | Сжатие |
| Loading | Действие дольше 300 мс | Действие можно отменить |
| Disabled | Действие недоступно | Действие заблокировано |
| Focus | Навигация с клавиатуры | Видимый Focus Ring |

## Композиция

Пара "Primary + Secondary" или "Primary + Ghost":

* Слева: отмена/назад (Secondary/Ghost);
* Справа: главное действие (Primary).

На mobile порядок может меняться: главное действие — сверху, отмена — снизу.

**Группа из 3+ кнопок**. Использовать Button Group или меню с действиями (Dropdown).

## **Доступность (A11y)**

* Контраст текста на фоне кнопки
* Видимый Focus Ring при навигации с клавиатуры (Tab);
* Кнопка активируется по Enter и Space;
* Если Icon Button, то обязателен aria-label;
* Для состояния Loading: aria-busy="true", aria-live для уведомления screen-reader;
* Для состояния Disabled: aria-disabled="true", но лучше избегать полного выключения tab-доступа (нужна причина в DOM).

## **Адаптив**

* На мобильных устройствах группы кнопок часто перестраиваются в вертикальный ритм (full-width);
* Full-width кнопка — приемлема для основного CTA на mobile, не для desktop;
* В таблицах на mobile действия скрываются в меню (... overflow), только одно, главное действие остается видимым.

## **Связанные компоненты**

* **Button Group** — связка из 2+ кнопок с общим контекстом;
* **Link** — для навигации без действия;
* **Toggle** — для переключения состояния.
