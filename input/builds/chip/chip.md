# Chip

Интерактивный компактный элемент для отображения и управления выбранными значениями, фильтрами или параметрами. Применяется в группах: фильтры в каталоге, выбранные опции в форме, теги с возможностью удаления, выбор из множества вариантов.

**Главное отличие от Badge**: Chip реагирует на действия пользователя — клик, выбор, удаление. Если взаимодействие не нужно — используй Badge.

## **Использовать**

* Можно взаимодействовать;
* Одиночный или множественный выбор;
* Фильтрация контента;
* Отображение значений, которые можно удалить;
* Внутренняя ссылка;
* Быстрые действия в каталоге;

## **Не использовать**

* Если нет взаимодействия, то используйте Badge;
* Если нужно выполнить действие, то используйте Button;
* Если переключаете состояние (on/off), то используйте Toggle;
* Если выбираете один из вариантов, то используйте Tabs или Segmented Control;
* Если нужна навигация, то используйте Tabs или Link;
* Если список длинный (более 10), то используйте Select / Multiselect.

## Вариант

| **Тип** | **Назначение** |
|----|----|
| Обычный | Стандартный чип с текстом. Базовый случай |
| С иконкой | Иконка слева для усиления смысла или отображения категории |
| С аватаром | Представление пользователя (упоминание, назначение исполнителя) |
| С группой аватаров | Представление команды / группы пользователей |
| Без текста | Только иконка или только аватар. Для очень плотных интерфейсов |

## **Поведение (режимы работы)**

Чип может работать в трёх режимах. Выбирайте режим под задачу:


1. **Toggle (выбор / отмена выбора)**

   Чип переключает состояние "выбран / не выбран" по клику.
   * **Где:** фильтры с множественным выбором, выбор тегов;
   * **Состояния:** Default (не выбран) ↔︎ Selected (выбран);
2. **Removable (удаляемый)**

   Чип отображает выбранное значение с иконкой «‎X» для удаления.
   * **Где:** уже выбранные значения в форме, в полях ввода;
   * **Поведение:** клик на «‎X» удаляет чип, клик в любой другой области, действие редактирование (опционально);
3. **Action (действие по клику)**

   Чип запускает действие: переход, открытие, фильтр.
   * **Где:** быстрые фильтры, теги-ссылки;
   * **Поведение:** клик инициирует действие, нет состояния "выбран".


:::warning
Не смешивайте режимы в одной группе. Если в фильтрах часть чипов toggle, а часть action, то пользователь не поймет логику.

:::

## **Стиль**

| **Стиль** | **Назначение** | **Где применять** |
|----|----|----|
| Soft | Спокойный, не перетягивает внимание | Стандартный случай. Большинство интерфейсов |
| Filled | Высокий контраст, привлекает внимание | Акцентные статусы и метки. |

## Цвет

#### **Варинт 1. Минимальная палитра**

Применяется в фильтрах, мультиселектах, token input, chip с аватаром.

| Цвет | Роль | Когда использовать | Стиль |
|----|----|----|----|
| `Grey` | Дефолт / нейтраль | Все обычные chip'ы: фильтры, токены, email, исполнители, теги поиска | `Soft` |
| `Blue` | Выбран / активен | Выбранный элемент в toggle-группе, активный quick filter | `Filled` для выбранного, `Soft` для наведения |
| `Red` | Невалидный ввод | Только ошибка валидации токена: битый email, дубликат | `Soft` |

#### **Варинт 2. П**олная палитра

Применяется только если в продукте есть пользовательская или системная цветовая кодировка, как в Notion / Linear / Trello.

| Цвет | Роль | Пример |
|----|----|----|
| `Grey` | Лейбл без цвета / по умолчанию | `Без категории` |
| `Blue` | Цвет-маркер категории | `Frontend` |
| `Green` | Цвет-маркер категории | `Дизайн` |
| `Yellow` | Цвет-маркер категории | `Маркетинг` |
| `Red` | Цвет-маркер категории | `Срочные`, как группа, не как ошибка |
| `Purple` | Цвет-маркер категории / премиум | `Исследования`, `AI` |
| `White` | Лейбл на темной подложке | В dark-теме / на цветном фоне |


:::warning
**Ключевое правило Варианта 2**. Цвет выбирается пользователем или администратором, а не привязан к смыслу системно. Поэтому любой Chip может быть любого цвета – это палитра, а не семантика.

:::

#### Матрица: какой путь когда применять

| Сценарий в продукте | Вариант | Нужные цвета |
|----|----|----|
| Фильтры над таблицей / каталогом | 1 | `Grey` + `Blue` |
| Мультиселект / выпадающий выбор | 1 | `Grey` + `Blue` |
| Token input: email, теги, навыки | 1 | `Grey` + `Red` для валидации |
| Chip с аватаром: исполнители, участники | 1 | `Grey` |
| Quick filters / toggle-группа | 1 | `Grey` для off + `Blue/Filled` для on |
| Пользовательские цветные лейблы | 2 | Вся палитра – 7 цветов |
| Системные цветные категории | 2 | Вся палитра – 7 цветов |

## Размер

| **Размер** | **Где применять** |
|----|----|
| **M** | Стандартный размер. Фильтры, выбор тегов в формах |
| **S** | Плотные интерфейсы, чипы внутри карточек, мобильные фильтры |


:::warning
Все чипы в одной группе — одного размера. Не смешивай M и S.

:::

## Форма

В дизайн-системе используются две формы Chip: **Circle** и **Square**. Они не являются визуальными вариантами одного компонента, а разделяются по смыслу сущности.

| Shape | Семантика | Используется для |
|----|----|----|
| Circle | Гибкая / человеко-ориентированная сущность | Теги, метки, категории, people chips, фильтры произвольных значений |
| Square | Структурная / системная сущность | Статусы, типы объектов, object chips, технические значения |

### Выбор формы

| Категория | Shape | Примеры |
|----|----|----|
| Теги и метки | Circle | #marketing, Срочно |
| Категории | Circle | Design, UI |
| People chips | Circle | Участник, Assignee, Reviewer |
| Фильтры произвольных значений | Circle | Регион: Москва |
| Статусы | Square | Active, Draft, Done |
| Типы объектов | Square | Task, Project, PDF |
| Object chips | Square | Проект, Команда, Интеграция, Бот |
| Технические значения | Square | v2.1.0, ID 1254 |

### **Связь с Avatar**

| Носитель | Avatar | Chip |
|----|----|----|
| Человек | Circle | Circle |
| Проект | Square | Square |
| Команда | Square | Square |
| Интеграция | Square | Square |
| Бот | Square | Square |

### **Исключение - Status**

Статус всегда отображается в **Square Chip**, даже если относится к человеку с круглым аватаром.

| Сценарий | Avatar | Status |
|----|----|----|
| Статус пользователя | Circle | Square |
| Статус проекта | Square | Square |
| Статус команды | Square | Square |

## **Счетчик**

Указывает на количество элементов (всего или выбранных): "Активные (42)".

* По дефолту нет ограничения на число;
* При превышении лимита (определяет дизайнер), формат **"N+"** или **"999+";**
* При 0 счетчик не показывается.

## **Иконка «‎X»**

* Используется только для Removable \*\*\*\*режима;
* Позиция: справа от текста;
* Кликабельная область: до границ чипа;
* Клик на X: удаляет чип. Не путать с кликом на тело чипа.

## **Ограничения**

* Рекомендуемая длина: до 20 символов;
* При превышении: обрезка с многоточием;
* Полный текст показывается в tooltip при наведении;
* Минимальная ширина чипа: задается на усмотрение дизайнера;

## Делать

* Один режим в одной группе (toggle/removable/action) ;
* Счетчик результатов отображается, если это помогает пользователю;
* Удаление через «‎X» должно работать без подтверждения;

## Не делать

* Не смешивайте разные стили в одной группе.
* Не смешивайте разные размеры в одной группе.

## **Группировка**

**Множественный выбор**. Список выбранных removable-чипов в форме над инпутом. Под инпутом, выпадающий список доступных опций.

**Категории/Теги в карточке.** Action-чипы для перехода к фильтру, ограничение по количеству (показывай 3-5, остальные "+N").

## Композиция

* Chip + Input: multi-select с поиском;
* Chip Group + Button "Сбросить": панель фильтров;
* Chip + Avatar: выбор пользователя/назначение;

## **Доступность (A11y)**

* Focus Ring при навигации с клавиатуры;
* Поддержка Enter и Space для активации;
* Removable-чип: иконка «‎X» это focusable элемент с aria-label="Удалить \[значение\]";
* Toggle-чип: aria-pressed="true/false" для screen-reader;
* Группа чипов: оборачивай в role="group" с aria-label, описывающим назначение группы.

## **Состояние**

| **Состояние** | **Описание** |
|----|----|
| **Default** | Базовое, доступен для взаимодействия |
| **Hover** | Курсор над чипом, легкая подсветка |
| **Pressed** | Mомент нажатия |
| **Selected** | Выбран / активен |
| **Focused** | Навигация с клавиатуры, видимый focus ring |
| **Loading** | Пока загружаются данные |
| **Disabled** | Недоступен (прим.: фильтр без результатов) |

## **Адаптив**

* На мобильных устройствах для группы чипов: горизонтальный скролл;
* Removable-чипы: на мобильных устройствах перестраиваться вертикально (при длинных значениях);
* На мобильных устройствах размер S остается размером M (пальцем сложнее попасть в маленький чип).
