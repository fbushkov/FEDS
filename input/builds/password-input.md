# Password Input   
Password Input — однострочное поле для ввода пароля, скрытого за символами маскировки, с возможностью показать введённое значение.   
Наследует оболочку Input (`input.md`, раздел «Оболочка поля (база семейства)»). Отличие — кнопка Show / Hide, которая переключает видимость значения и имеет собственное состояние «нажата».   
Label, Description с требованиями к паролю и сообщения относятся к Field.   
## Использовать   
- Для входа по паролю;   
- Для создания и смены пароля;   
- Для других секретов, которые не должны быть видны по умолчанию: ключ доступа, PIN.   
   
## Не использовать   
|                                                                             **Задача** |                             **Компонент** |
|:---------------------------------------------------------------------------------------|:------------------------------------------|
|                                                             Одноразовый код из SMS или письма |     Input, `inputmode="numeric"` (`input.md`, «Типы значения») |
|                           Значение, которое не секретно, но должно быть скрыто в интерфейсе |                                     Input |
|                                                            Показать ключ только для копирования |                Input в Read Only с Action «Скопировать» |

Высоты и отступы — как у Input того же размера. Кнопка Show / Hide масштабируется вместе с полем, как Clear.   
## Содержимое   
### Show / Hide   
- Кнопка переключает значение между скрытым и видимым видом;   
- Иконка показывает текущее действие: «глаз» — показать, «перечёркнутый глаз» — скрыть;   
- После переключения фокус остаётся на кнопке, а каретка в поле — на прежнем месте;   
- При отправке формы значение снова скрывается, чтобы браузер не сохранил его как обычный текст.   

### Требования к паролю   
- Для нового пароля перечислите требования в Description до ввода, а не в Placeholder;   
- Не прячьте требования только в Tooltip;   
- Индикатор надёжности пароля — отдельный компонент (позже), не часть поля.   

### Повторный ввод   
Вместо второго поля «Повторите пароль» используйте Show / Hide: пользователь может проверить значение глазами. Второе поле нужно, только если этого требуют правила безопасности продукта.   
## Состояния   
Состояния — как у оболочки Input.   
|        **Состояние** |                                                                   **Отличие** |
|:---------------------|:------------------------------------------------------------------------------|
|             Disabled |                                          Show / Hide не показывается |
|            Read Only |                                  Show / Hide доступна: это действие, а не правка |
|              Warning |                          Включён Caps Lock: «Включён Caps Lock» в Validation Message |
|              Loading |                                            Spinner, например при проверке пароля на сервере |

## Валидация   
- Error показывайте после отправки или ухода из поля, а не на каждый символ;   
- Текст ошибки называет невыполненное требование: «Минимум 8 символов», а не «Неверный формат»;   
- При неверном пароле при входе не уточняйте, что именно неверно — логин или пароль, если этого требуют правила безопасности;   
- Не очищайте поле после ошибки проверки на клиенте: пользователь исправляет значение, а не вводит заново.

## Доступность (A11y)   
- Используйте `<input type="password">` и переключайте `type` на `text` при показе;   
- Укажите `autocomplete="current-password"` для входа и `autocomplete="new-password"` для создания пароля: так работают менеджеры паролей;   
- Не запрещайте вставку и автозаполнение: WCAG 2.2, критерий 3.3.8, требует, чтобы вход не зависел от запоминания и переписывания пароля;   
- Show / Hide — кнопка-переключатель: доступное имя постоянное («Показать пароль»), состояние передаёт `aria-pressed`. По WAI-ARIA APG имя переключателя не должно меняться вместе с состоянием;   
- Сообщайте о смене видимости через live-region: «Пароль показан» / «Пароль скрыт»;   
- Отключите проверку орфографии и автоматическую заглавную букву (`spellcheck="false"`, `autocapitalize="off"`);   
- Требования к паролю связывайте с полем через `aria-describedby`.   

## Управление клавиатурой   
|          **Действие** |                                                                                  **Результат** |
|:----------------------|:-----------------------------------------------------------------------------------------------|
|                   Tab |                                               Переводит фокус в поле, затем на Show / Hide |
|           Shift + Tab |                                                                         Перемещает фокус назад |
|  Enter / Space на Show / Hide |                                         Переключает видимость; фокус остаётся на кнопке |
|          Enter в поле |                                                                                  Отправляет форму |
|     Стрелки, Home / End |                                                Перемещают каретку внутри текста |
|            Ctrl/Cmd + V |                              Вставляет значение, в том числе из менеджера паролей |

## Делать   
- Давать возможность показать пароль;   
- Показывать требования к новому паролю до ввода;   
- Указывать правильный `autocomplete`;   
- Скрывать значение снова при отправке формы.   

## Не делать   
- Не запрещать вставку;   
- Не менять доступное имя кнопки при переключении — используйте `aria-pressed`;   
- Не показывать Clear: удалить значение можно клавиатурой, а случайное нажатие стирает долгий ввод;   
- Не объяснять требования только в Placeholder или Tooltip;   
- Не использовать Password Input для несекретных значений.

## Решения для согласования   
*(docs-writer 19.09.2026)*   
1. **Отдельный компонент:** новая часть с собственным состоянием (переключатель с `aria-pressed`) (`docs/forms-architecture.md`, раздел 5).   
2. **Show / Hide — Icon Button на месте Action-1,** второе действие допускается, Clear и Suffix не используются.   
3. **Имя кнопки постоянное, состояние в `aria-pressed`,** плюс сообщение в live-region. Альтернатива (так делает GOV.UK) — текстовая кнопка «Показать» / «Скрыть».   
4. **Caps Lock — Warning с текстом,** опционально.   
5. **В Read Only Show / Hide доступна,** в Disabled не показывается (по аналогии с Actions в макете Input).   
6. **Повторное поле пароля не рекомендуется** — только по требованию безопасности.
