# Divider

Базовый визуальный компонент для разделения и группировки содержимого на явные секции. Он представляет собой тонкую горизонтальную или вертикальную линию, которая разбивает интерфейс на тематические блоки.

## **Применять**

#### **Группировка элементов**

Разделяйте связанные группы элементов и пунктов меню. Например, в боковом меню между разными группами навигации ставятся горизонтальные Divider.

#### **Разделение секций формы или интерфейса**

Используйте Divider для отделения логически разных блоков в формах, панелях инструментов, карточках и т.д. Например, отделение шапки или фильтров от остального содержания.

#### **Вертикальные разделители в ряду.**

Внутри одной строки Divider может отделять соседние элементы (например, кнопки тулбара, метаданные).

#### **Альтернативные блоки**

Выделяйте вариант «или» между альтернативными секциями. Классический пример — разделение способов входа (например, через социальные сети или по email).


## **Не применять**

#### **Не вместо пробела**

Если блоки можно логично разделить пустым пространством (white space), нет необходимости добавлять видимый Divider. В подобных случаях часто достаточно увеличить отступы или интервалы.

#### **Не для «декора»**

Divider должен помогать понять структуру, а не просто украшать интерфейс. Не используйте Divider только ради визуального эффекта без смысловой нагрузки.

#### **Не злоупотреблять**

Несколько Divider подряд или чрезмерное их количество захламляют интерфейс. Один Divider между двумя зонами обычно достаточно.

#### **Не для интерактивности**

Divider — статический элемент. Если нужна интерактивная разделительная функциональность (например, кликабельный переключатель), используется иной компонент. Divider не кликабелен, не фокусируется и не имеет состояний наведения или нажатия.
