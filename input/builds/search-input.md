# Search Input   
Search Input — однострочное поле для поиска объекта или контента по запросу.   
Наследует оболочку Input (`input.md`, раздел «Оболочка поля (база семейства)»). Здесь описаны только отличия: фиксированная иконка поиска, постоянный Clear при наличии значения и своя клавиатурная модель — Enter запускает поиск, Escape очищает запрос.   
Label, Description и сообщения относятся к Field. В панелях и тулбарах Search Input используется без Field, но с доступным именем.   
## Использовать   
- Для поиска по списку, таблице, разделу или всему продукту;   
- Для фильтрации видимого набора данных по тексту;   
- Когда пользователь сам формулирует запрос.   
   
## Не использовать   
|                                                                            **Задача** |                             **Компонент** |
|:--------------------------------------------------------------------------------------|:------------------------------------------|
|                                   Выбрать одно значение из справочника с подсказками |                                  Combobox |
|                                     Выбрать значение из короткого известного списка |                                    Select |
|                                           Ввести значение, которое сохранится в форме |                                     Input |
|                                     Отфильтровать по нескольким признакам сразу |           Filter Bar (позже) |

💡   
Если под полем появляется список подсказок, из которого выбирают значение, это уже Combobox с поиском, а не Search Input.   
   
## Конфигурация   
|      **Зона** |                           **Содержимое** |                                                    **Отличие от Input** |
|:--------------|:-----------------------------------------|:------------------------------------------------------------------------|
|  Leading Zone |                         Icon «Поиск» |                         Иконка обязательна и не меняется; Prefix не используется |
|       Content |                    Placeholder или Value |                                                             Как у Input |
| Trailing Zone |          Clear, Action-1, Spinner |           Suffix, Action-2 и State Icon не используются |

- **Clear** показывается всегда, когда есть значение (у Input он по умолчанию выключен);   
- **Action-1** — одно действие над запросом: область поиска, фильтр, голосовой ввод. Больше одного действия не добавляйте;   
- **Spinner** — пока загружаются результаты.   

## Размеры   
|       **Размер** |                                                                         **Где применять** |
|:-----------------|:------------------------------------------------------------------------------------------|
|                S |                                        Тулбары таблиц, фильтры, боковые панели |
|                M |                                                   Поиск по разделу, стандартный вариант |
|                L |                          Главный поиск страницы, пустые состояния с поиском |

Высоты и отступы — как у Input того же размера.   
## Содержимое   
**Placeholder** называет, где ищем: «Поиск по заказам», «Имя или email». Он не заменяет доступное имя поля.   
- Не пишите в Placeholder «Введите запрос»: иконка уже сообщает, что это поиск;   
- Не показывайте в поле количество результатов — оно относится к списку результатов.   

### Когда запускается поиск   
|             **Режим** |                                                      **Когда применять** |
|:----------------------|:-------------------------------------------------------------------------|
|  По мере ввода |                    Локальная фильтрация или быстрый ответ системы; запрос с задержкой после ввода |
|  По Enter |                                     Дорогой запрос или поиск по всему продукту |

В одном продукте для одинаковых сценариев используйте один режим.   
## Состояния   
Состояния — как у оболочки Input: Default, Hover, Focused, Disabled, Read Only, Loading.   
|        **Состояние** |                                                                   **Отличие** |
|:---------------------|:------------------------------------------------------------------------------|
|              Loading |                 Spinner, пока загружаются результаты; ввод не блокируется |
|            Read Only |                    Практически не используется: поиск без правки запроса не нужен |
| Error / Warning / Success |                      Обычно не нужны: пустой результат — не ошибка поля |

## Валидация   
Search Input почти не валидируется: любой запрос допустим.   
- Пустой результат показывайте в области результатов (Empty State), а не как Error поля;   
- Error допустим только для технического ограничения, например «Минимум 3 символа». Такое требование лучше показать заранее в Description.   

## Regular и Inverse   
|      **Режим** |                                               **Где применять** |
|:---------------|:----------------------------------------------------------------|
|        Regular |                               Светлые и стандартные поверхности |
|        Inverse |                                              Темные поверхности |

## Доступность (A11y)   
- Используйте `<input type="search">`: у него уже есть роль searchbox;   
- Поле поиска по странице или разделу помещайте в область с ролью `search` (элемент `<search>` или `role="search"`);   
- Доступное имя обязательно. Без видимого Label используйте `aria-label`, например «Поиск по заказам». Placeholder не заменяет имя;   
- Иконка поиска декоративная: скрывайте её от screen reader;   
- Clear — кнопка с доступным именем «Очистить поиск». После очистки фокус остаётся в поле;   
- Об изменении числа результатов сообщайте через live-region без переноса фокуса (WCAG 2.2, критерий 4.1.3);   
- Горячая клавиша фокуса на поиск (например, `/`) допустима, только если её можно отключить или она не срабатывает в текстовых полях (WCAG 2.2, критерий 2.1.4).   

## Управление клавиатурой   
|          **Действие** |                                                                                  **Результат** |
|:----------------------|:-----------------------------------------------------------------------------------------------|
|                   Tab |                                      Переводит фокус в поле, затем на Clear и Action-1 |
|           Shift + Tab |                                                                         Перемещает фокус назад |
|                 Enter |                                    Запускает поиск (в режиме «По Enter») |
|                Escape |                             Очищает запрос; фокус остаётся в поле |
|     Стрелки, Home / End |                                                Перемещают каретку внутри текста |
| Ctrl/Cmd + A, C, V, X |                           Стандартные операции выделения, копирования и редактирования |

## Делать   
- Называть в Placeholder область поиска;   
- Показывать Clear, как только появилось значение;   
- Показывать Spinner, пока загружаются результаты;   
- Сохранять запрос в поле после поиска;   
- Давать полю ширину под типичный запрос.   

## Не делать   
- Не делать иконку поиска единственной подписью поля без доступного имени;   
- Не показывать пустой результат как Error;   
- Не добавлять в поле больше одного действия;   
- Не использовать Search Input для выбора значения из справочника — для этого есть Combobox;   
- Не сбрасывать запрос после перехода к результатам.   

## Связанные компоненты   
|          **Компонент** |                                            **Когда использовать** |
|:-----------------------|:------------------------------------------------------------------|
|                  Input |                   Базовая оболочка; ввод значения для формы |
|               Combobox |                       Поиск с выбором значения из подсказок |
|                  Field |                     Search Input внутри формы: Label, Description |
|            Empty State |                                      Результатов не найдено |
|                Spinner |                                   Загрузка результатов |

## Решения для согласования   
*(docs-writer 19.09.2026)*   
1. **Отдельный компонент, а не настройка Input:** своя клавиатурная модель (Escape очищает, Enter запускает поиск) и своя роль searchbox (`docs/forms-architecture.md`, раздел 5).   
2. **Иконка «Поиск» обязательна и не заменяется;** Prefix не используется.   
3. **Clear всегда виден при значении,** а не по Hover, как допускает Input.   
4. **В Trailing Zone не больше одного Action;** Suffix, Action-2 и State Icon не используются.   
5. **Без Field в панелях и тулбарах,** с `aria-label`. В форме — сборка Search Field.   
6. **Форма контейнера — общий радиус контролов** (`filosofiya-form.md`: управление использует единый radius), без «таблетки».
