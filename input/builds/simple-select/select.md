# Select   
Select — компонент для выбора одного значения из заранее известного набора вариантов. Пользователь открывает Dropdown, выбирает Dropdown Item, после чего выбранное значение отображается в Select Button.   
Компонент состоит из трех частей:   
|      **Часть** |                                                                                               **Назначение** |
|:---------------|:-------------------------------------------------------------------------------------------------------------|
|  Select Button |                                                   Показывает текущее значение и открывает / закрывает список |
|       Dropdown |                                                                               Контейнер со списком вариантов |
|  Dropdown Item |                                                          Отдельный вариант, заголовок группы или разделитель |

💡   
Label, Description и текст валидации относятся к обертке поля — Field.   
   
## Использовать   
- Для выбора одного значения из списка;   
- Когда варианты известны заранее;   
- Для форм, фильтров и предустановленных настроек;   
- Оптимально — для списка примерно из 5–25 вариантов.   
   
## Не использовать   
|                                                               **Задача** |             **Компонент** |
|:-------------------------------------------------------------------------|:--------------------------|
|                                 Вариантов до 5 и их полезно видеть сразу | Radio / Segmented Control |
|                                          Вариантов много или нужен поиск |                  Combobox |
|                                         Можно выбрать несколько значений |               Multiselect |
|                                       Нужно ввести произвольное значение |                     Input |
|                                     Нужно включить / выключить настройку |                    Switch |

Select не поддерживает свободный ввод. Если пользователь должен искать по большому справочнику или вводить текст, используйте Combobox.   
   
## Размеры   
Select, Select Button, Dropdown и Dropdown Item поддерживают размеры S / M / L.   
|       **Размер** |                                                                                                 **Где применять** |
|:-----------------|:------------------------------------------------------------------------------------------------------------------|
|                S |                                                                                  Таблицы, фильтры, плотные панели |
|                M |                                                                           Стандартный размер для большинства форм |
|                L |                                                      Крупные формы и сценарии с повышенным визуальным приоритетом |

## Отличия от оболочки Input (добавлено docs-writer 19.09.2026)   
Select Button наследует оболочку Input (`input.md`, раздел «Оболочка поля (база семейства)»): контейнер, обводку и фон по состояниям, Placeholder / Value, Leading Zone, Clear, State Icon и Spinner. Ниже — только отличия.   
|        **Что** |                                    **Input** |                                                                   **Select Button** |
|:---------------|:---------------------------------------------|:------------------------------------------------------------------------------------|
|        Chevron |                                          Нет |                         Всегда есть, последним в Trailing Zone: после State Icon / Spinner |
|  Open Dropdown |                                          Нет |              Признак раскрытия списка; существует параллельно с Focused (см. «Focused и Open») |
|  Свободный ввод |                                           Да |                              Нет: значение выбирается только из Dropdown, каретки нет |
|        Pressed |               Нет, после клика — Focused |                          Есть: Select Button — кнопка, нажатие открывает Dropdown |
|    Suffix, Actions |                               Да |                                                       Нет, кроме Clear |
|       Роль ARIA |                             Текстовое поле |                                  Select-only combobox (см. «Доступность») |

# Select Button   
Select Button показывает Placeholder или выбранное значение и управляет открытием Dropdown.   
## Содержимое   
|          **Элемент** |                                                                      **Назначение** |
|:---------------------|:------------------------------------------------------------------------------------|
|         Leading Icon |                                         Дополнительный контекст выбранного значения |
|          Placeholder |                                                         Подсказка в Empty-состоянии |
|                Value |                                                          Текущее выбранное значение |
|                Clear |                                                           Сброс выбранного значения |
| State Icon / Spinner |                                  Error / Warning / Success или асинхронная проверка |
|              Chevron |                                              Показывает возможность раскрыть список |

## Empty и Filled   
|        **Вариант** |                                                                          **Описание** |
|:-------------------|:--------------------------------------------------------------------------------------|
|              Empty |                                   Значение не выбрано, может отображаться Placeholder |
|             Filled |                                       Значение выбрано и отображается в Select Button |

- Если система может определить корректное значение по умолчанию, показывайте его сразу. Если нет — используйте Empty и Placeholder, например «Выберите».   
- Placeholder не показывается как отдельный пункт в Dropdown.   
   
   
## Clear   
Clear ( `×`) нужен только тогда, когда пользователь может вернуться к состоянию «ничего не выбрано».   
- Показывается только при наличии значения;   
- Не используется в Disabled и Read Only;   
- После очистки фокус остается на Select Button;   
- Если значение обязательно, Clear обычно не нужен;   
- Альтернатива — отдельный пункт «Все», «Любой», «Неважно» в Dropdown.   
   
## Длинное значение   
Select Button остается однострочным.   
- Если Value не помещается, используется многоточие;   
- Полный текст доступен в Tooltip;   
- Chevron, Clear и системные иконки не сдвигаются;   
- Ширина Select должна учитывать типичную длину значений.   
   
## Состояния Select Button   
|          **Состояние** |                                                                                     **Когда применяется** |                                                    **Поведение** |
|:-----------------------|:----------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------|
|                Default |                                                                                  Select закрыт и доступен |                                                Базовое состояние |
|                  Hover |                                                                                  Курсор над Select Button |                                                        Подсветка |
|                Pressed |                                                                                            Момент нажатия |                                                Состояние нажатия |
|          Open Dropdown |                                                                                             Список открыт |                       Chevron меняет направление, Dropdown видим |
|               Disabled |                                                                                          Выбор недоступен |                                             Нет открытия и Clear |
|              Read Only |                                                    Значение доступно для чтения, но выбор нельзя изменить |                                          Dropdown не открывается |
|                  Error |                                                   Выбор некорректен или обязательное значение отсутствует |                                     Error-оформление + сообщение |
|                Warning |                                                                   Значение допустимо, но требует внимания |                                   Warning-оформление + пояснение |
|                Success |                                                                                 Выбор успешно подтвержден |                             Success-оформление при необходимости |
|                Loading |                                                             Идет асинхронная проверка выбранного значения |                                      Spinner в системной позиции |

Focused и Open
Focused описывает клавиатурный фокус, Open Dropdown — факт раскрытия списка. Это разные признаки и они могут существовать одновременно.
Визуально Open может использовать ту же активную обводку, что и Focused, но в логике компонента их не следует объединять.   
   
## Валидация   
Для Select основная ошибка — обязательное значение не выбрано. Варианты, которые заведомо приведут к ошибке, лучше скрыть или сделать недоступными в списке.   
- Error сопровождается текстовым сообщением;   
- Warning не блокирует выбор;   
- Success используйте только когда подтверждение действительно полезно.   
   
## Асинхронная проверка   
Spinner в Select Button относится к проверке **выбранного значения** после выбора.   
Последовательность:   
1. Пользователь выбирает значение;   
2. В Select Button появляется Spinner;   
3. После ответа системы Spinner исчезает или заменяется Error / Warning / Success.   
   
Не путайте это состояние с Loading самого Dropdown, когда загружается список вариантов.   
   
# Dropdown и Dropdown Item   
Разделы «Dropdown» и «Dropdown Item» перенесены без изменений в общую базу списка — `dropdown.md`. Она общая для Select, Combobox, Multiselect, позже Menu и Autocomplete. (добавлено docs-writer 19.09.2026)   
Особенности Select, которые дополняют `dropdown.md`: (добавлено docs-writer 19.09.2026)   
- **Режим single** — выбрано не больше одного значения, после выбора Dropdown закрывается;   
- **Check Indicator** — опциональный индикатор выбранного пункта; Checkbox в Select не используется;   
- **«Все», «Любой», «Неважно»** — отдельный пункт сброса вместо Clear, его можно отделить Divider;   
- **Placeholder — не пункт списка**: он показывается только в Select Button в состоянии Empty;   
- **Нет поиска, «Создать …» и подсветки совпадения** — это возможности Combobox;   
- **Размер Dropdown и Dropdown Item** равен размеру Select.

## Управление клавиатурой   
|                         **Действие** |                                                                                  **Результат** |
|:-------------------------------------|:-----------------------------------------------------------------------------------------------|
|                                  Tab |                                         Переводит фокус на Select и далее на следующий контрол |
|                    Enter / Space / ↓ |                                                                    Открывает закрытый Dropdown |
|                                ↑ / ↓ |                                                       Перемещает Active по доступным вариантам |
|                           Home / End |                                                      Переходит к первому / последнему варианту |
|                        Enter / Space |                                                      Выбирает Active Item и закрывает Dropdown |
|                               Escape |                                                      Закрывает Dropdown без изменения значения |
|            Tab при открытом Dropdown |                                                    Закрывает список и продолжает Tab-навигацию |
| ↑ на закрытом Select (добавлено docs-writer 19.09.2026) | Открывает Dropdown, Active — на выбранном варианте, а если его нет — на первом |
| Буква или цифра (добавлено docs-writer 19.09.2026) | Открывает Dropdown и переводит Active к первому варианту, который начинается с набранных символов (набор подряд уточняет поиск) |
| Alt + ↑ при открытом Dropdown (добавлено docs-writer 19.09.2026) | Выбирает Active Item и закрывает Dropdown |

💡   
Недоступные, Group Title и Divider пропускаются при клавиатурной навигации.   
   
## Доступность (A11y)   
Для простого сценария предпочтителен нативный . Если дизайн требует кастомного Select:   
- Select Button реализуется как select-only combobox с доступным именем;   
- Используйте *role="combobox"*, *aria-expanded* и *aria-controls*;   
- Dropdown получает *role="listbox"*;   
- Value Item получает *role="option"* и *aria-selected*;   
- Для управления визуальным Active Item используйте *aria-activedescendant*;   
- Недоступному варианту задавайте *aria-disabled="true"*;   
- Group Title не должен объявляться как selectable option;   
- Divider скрывайте от screen reader как декоративный элемент;   
- Check Indicator и декоративные Leading Icon скрывайте через *aria-hidden="true"*;   
- Label и сообщения валидации связывайте с Select программно;   
- Error передавайте через *aria-invalid="true"* и связанное текстовое сообщение;   
- Focus Ring должен быть видим при клавиатурной навигации;   
- Не создавайте отдельную Tab-остановку для каждого Dropdown Item.   
   
💡   
**Selected** — это выбранное значение, **Active** — пункт, на котором сейчас находится клавиатурная навигация. Эти состояния могут выглядеть похоже, но не должны смешиваться в семантике.   
## Адаптив   
- На узком экране Select Button может занимать доступную ширину;   
- Dropdown должен оставаться полностью видимым в viewport;   
- Если desktop-позиционирование не помещается, список можно перестраивать в широкую мобильную панель;   
- Не уменьшайте текст и активные области ради сохранения desktop-ширины.   
   
## Делать   
- Использовать Select для одного значения из известного списка;   
- Использовать Scroll при количестве вариантов больше 10;   
- Разделять Selected и Active;   
- Объяснять Error текстом.   
   
## Не делать   
- Не использовать Select для множественного выбора;   
- Не добавлять свободный ввод;   
- Не делать Dropdown уже Select Button;   
- Не показывать Placeholder среди Dropdown Item;   
- Не оставлять длинный список без Scroll.   
   
## Связанные компоненты   
|          **Компонент** |                                                             **Когда использовать** |
|:-----------------------|:-----------------------------------------------------------------------------------|
|                  Field |                                  Label, Description, Required и Validation Message |
|                  Radio |                                       До 5 вариантов, которые полезно видеть сразу |
|      Segmented Control |                                       Небольшой набор коротких вариантов / режимов |
|               Combobox |                                                 Большой список или требуется поиск |
|            Multiselect |                                                   Можно выбрать несколько значений |
|                  Input |                                          Пользователь вводит произвольное значение |
|               Dropdown |                                                        Контейнер со списком Select |
|          Dropdown Item |                                                  Отдельный вариант внутри Dropdown |

2. **Chevron — последним в Trailing Zone**, после State Icon / Spinner. Порядок совпадает с таблицей «Содержимое» выше и с `docs/forms-architecture.md`. **Принято пользователем 19.09.2026:** Chevron всегда последний в правой зоне, после Clear и State Icon / Spinner.
