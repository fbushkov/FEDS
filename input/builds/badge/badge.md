# Badge

Неинтерактивный информационный компонент. Небольшая текстовая метка с опциональной иконкой и семантическим цветом, показывающая статус, категорию или метаданные. Бейдж нельзя кликать, наводить с эффектом или закрывать, он служит исключительно для информирования.

Главное отличие от Chip: Badge не реагирует на действия пользователя. Если нужно взаимодействие (выбор, удаление, фильтр) — используй Chip.

## **Использовать**

* Показать статус: "Активен", "В работе", "Просрочено";
* Указывать на категорию или тип: "Бесплатно", "Pro", "Beta";
* Метаданные рядом с заголовком, именем, пр.

## **Не использовать**

* Если можно кликнуть, то используйте Chip;
* Если нужно выбрать фильтр, то используйте Chip;
* Если можно удалить, то используйте Chip с иконкой «‎X»;
* Если нужно выполнить действие, то используйте Button.

## Вариант

| Вариант | Когда применять |
|----|----|
| Dot Status | Индикатор состояния, цветная точка рядом с именем |
| Text | Стандартный случай: текстовая метка статуса или категории |
| Counter | Числовые значения: количество уведомлений, задач, новых сообщений |
| Text + Icon | Когда иконка усиливает смысл: ✓ "Выполнено", ⚠ "Внимание" |
| Only Icon | Очень плотные интерфейсы, где нет места для текста. Обязателен tooltip |


:::warning
Для стиля **Filled** нет варианта Dot Status — роль цветового индикатора уже выполняет сам фон бейджа.

:::

## Стиль

| **Стиль** | **Назначение** | **Где применять** |
|----|----|----|
| Soft | Спокойный, не перетягивает внимание | Стандартный случай. Большинство интерфейсов |
| Filled | Высокий контраст, привлекает внимание | Критичные статусы, акцентные метки ("New", "Hot"), счётчики на иконках в шапке |

## Цвет

Цвет бейджа несет смысл, выбирай по семантике, а не по эстетике:

| **Цвет** | **Семантика** | **Примеры** |
|----|----|----|
| Neutral / Grey | Нейтральная информация | "Черновик", "Архив", "Beta" |
| Blue / Info | Информация, статус "В процессе" | "В работе", "На рассмотрении" |
| Green / Success | Успех, положительный статус | "Активен", "Оплачено", "Онлайн" |
| Yellow / Warning | Внимание, требует действия | "Ожидает", "Истекает" |
| Red / Error | Ошибка, негативный статус | "Просрочено", "Отклонено", "Офлайн" |
| Brand colors | Категории, теги без негативного значения | "Premium", "Pro", "Новинка" |


:::warning
Не используйте цвет как единственный носитель смысла, всегда дублируйте текстом или иконкой. Цветовая слепота встречается у \~8% мужчин.

:::

## **Счетчик**

Указывает на количество элементов (всего или выбранных): "Активные (42)".

* По дефолту нет ограничения на число;
* При превышении лимита (определяет дизайнер), формат "N+" или "999+";
* Для Dot Status счетчик не используется;
* При 0 счетчик не показывается.

## Форма

| **Форма** | **Когда применять** |
|----|----|
| **Circle** | Стандартный случай. Универсально |
| **Square** | Когда нужен более "технический" вид: коды, версии, метки в таблицах |


:::warning
В рамках одного интерфейса используй только одну форму. Не смешивай circle и square — это нарушает визуальную систему.

:::

## Аватар

* **Circle (круглый)** — человек / персона.Используется для людей и человеко-ориентированных сущностей: пользователи, ассайни, участники, комментаторы, авторы, профили, упоминания.
* **Square (квадратный)** — объект / система. Используется для нечеловеческих и структурных сущностей: компании, проекты, команды, интеграции, файлы, боты, сервисы.

## Размер

| **Размер** | **Где применять** |
|----|----|
| **M** | Стандартный размер. Рядом с заголовками, в карточках, таблицах |
| **XS** | Очень плотные интерфейсы, поверх аватара, в строках статуса |

## **Ограничения**

* Рекомендуемая длина: до 15 символов
* Максимальная: 30 символов, при превышении многоточие;
* Полный текст показывается в tooltip при наведении;
* Минимальная ширина чипа: задается на усмотрение дизайнера;

## Делать

* Цвет соответствует семантике статуса;
* Один стиль (Soft или Filled) для одного типа меток;
* Tooltip для длинного текста и Only Icon.

## Не делать

* Не используйте цвета бессмысленно ;
* Не используй счетчик "0", скрывайте бейдж полностью;
* Не смешивай формы (Circle + Square) в одном контексте.

## Композиция

* Badge + Icon (в навигации) Counter поверх иконки в шапке/меню. Показывает количество непрочитанных уведомлений, сообщений.
* Badge + Заголовок / Имя Метка статуса справа от текста. Размер бейджа — на одну ступень меньше или равен размеру текста.
* Badge в Table / List Статус сущности в колонке таблицы. Используй один стиль и одну форму на всю таблицу.

## **Доступность (A11y)**

* Цвет дублируй текстом или иконкой (для colorblind-пользователей);
* Only Icon: обязательный tooltip с расшифровкой смысла;
* Counter: озвучивай число screen-reader'у через aria-label: "5 непрочитанных уведомлений", а не просто "5";
* Badge не имеет focus. Не должен попадать в Tab-навигацию.

## Состояние

| Состояние | **Назначение** |
|----|----|
| Default | Единственное основное состояние |
| Loading | Пока загружаются данные |
| Hover / Pressed / Focused | Отсутствуют, так как Badge не интерактивен |
