# Breadcrumbs
Breadcrumbs — строка ссылок, которая показывает положение текущей страницы в иерархии разделов и даёт вернуться на любой уровень выше. Крошки отражают **структуру системы**, а не историю переходов пользователя.

Документа пользователя по Breadcrumbs нет: текст написан по WAI-ARIA APG (`breadcrumb`), WCAG 2.2 (2.4.8 Location, 2.4.4 Link Purpose, 2.5.8 Target Size, 1.4.11 Non-text Contrast) и практике Material, Carbon, Atlassian, Polaris, Primer, GOV.UK. Свои числа и решения собраны в разделе «Решения для согласования». (docs-writer 20.09.2026)

| **Часть** | **Назначение** |
|:--|:--|
| Breadcrumbs | Контейнер `nav` с доступным именем |
| Item | Ссылка на уровень выше |
| Separator | Знак между уровнями, декоративный |
| Current | Текущая страница: последний элемент, не ссылка |
| Overflow | Кнопка «…» со скрытыми уровнями и её Menu |

💡
Крошки отвечают на вопрос «где я и как подняться выше». Они не заменяют основную навигацию и не повторяют кнопку «Назад» браузера: та ведёт на предыдущую страницу, а крошка — на родительский раздел, где пользователь мог ни разу не быть.

## Навигация: когда что
| **Задача** | **Компонент** |
|:--|:--|
| **Показать положение страницы в иерархии и дать подняться выше** | **Breadcrumbs** |
| Переключить панели внутри одной страницы | Tabs |
| Провести по шагам с порядком и валидацией | Stepper |
| Перейти в раздел системы из постоянного меню | Sidebar / Nav Item |
| Вернуться на одну страницу назад | Back Link |
| Листать длинный список по страницам | Pagination |
| Выполнить команду | Menu / Button |

## Использовать
- В системах с вложенностью от трёх уровней: «Проекты → Проект → Задача»;
- На странице объекта, куда можно попасть из разных мест — из поиска, из ссылки, из уведомления;
- В каталогах, справочниках, файловых деревьях, настройках с подразделами;
- Когда пользователю нужно не только вернуться, но и понять, частью чего является страница (WCAG 2.4.8 Location, уровень AAA).

## Не использовать
| **Задача** | **Компонент** |
|:--|:--|
| Иерархия плоская: все страницы на одном уровне | Ничего не нужно |
| Уровень ровно один («Главная → Страница») | Back Link или ничего |
| Шаги процесса по порядку | Stepper |
| Панели одного экрана | Tabs |
| Показать историю переходов пользователя | Кнопка «Назад» браузера |
| Единственный способ навигации в системе | Sidebar + Breadcrumbs вместе |

## Breadcrumbs, Tabs и Stepper
| **Признак** | **Breadcrumbs** | **Tabs** | **Stepper** |
|:--|:--|:--|:--|
| Что показывают | Путь по иерархии сверху вниз | Равнозначные панели одного экрана | Шаги одного процесса по порядку |
| Элементы | Ссылки на разные страницы | Ярлыки одной страницы | Шаги, часть недоступна |
| Порядок | Фиксирован иерархией | Произвольный | Последовательный, есть пройденные и будущие |
| Текущий элемент | Не ссылка, `aria-current="page"` | `aria-selected="true"` | `aria-current="step"` |
| Что меняется при нажатии | Адрес и вся страница | Только панель | Шаг мастера |
| Разметка | `nav` + `ol` + `li` | `tablist` + `tab` + `tabpanel` | `ol` со ссылками или кнопками |

Общая ошибка — сделать крошками ряд вкладок или шаги мастера. Признак крошек: каждый элемент ведёт на **отдельную страницу с собственным заголовком**.

## Состав и порядок
- Первый элемент — корень: «Главная» или название модуля. Иконку «дом» вместо слова использовать можно, но у неё обязательно доступное имя;
- Дальше идут разделы от общего к частному, ровно теми названиями, какие стоят в заголовках этих страниц;
- Последний элемент — текущая страница: **не ссылка**;
- Уровни не пропускаются: путь должен приводить туда же, куда приведёт навигация по ссылкам;
- Идеальная длина — 3–5 уровней; при большем числе включается сокращение;
- Крошки стоят над заголовком страницы, в одном с ним контейнере, и не «прилипают» при прокрутке.

**Текущая страница.** Возможны два варианта, и оба встречаются в практике:

| **Вариант** | **Как** | **Когда** |
|:--|:--|:--|
| Показывать (по умолчанию) | Последний элемент — текст, `aria-current="page"`, цвет `color/static/text/neutral/primary` | Заголовок страницы длинный или отличается от названия в пути |
| Не показывать | Путь заканчивается родителем, текущую страницу называет заголовок H1 (приём GOV.UK) | Заголовок страницы повторяет название и стоит сразу под крошками |

Текущая страница никогда не делается кликабельной ссылкой «на саму себя».

## Разделитель
- Знак между уровнями: шеврон «›» (по умолчанию) или косая черта «/»;
- Один знак на всю систему; менять его в разных разделах нельзя;
- Разделитель декоративен: он вставляется оформлением или помечается `aria-hidden="true"` — screen reader не должен читать «слэш» между уровнями;
- Цвет — `color/static/icon/neutral/tertiary`, он заметно слабее ссылок;
- Размер иконки-шеврона — `size/icon/xs` (12) при тексте 14 / 20;
- Отступ с каждой стороны — `space/inline/tight` (4), между названиями получается 8;
- Стрелка «→» не используется: она читается как переход вперёд, а крошки ведут вверх.

## Размеры и токены
У Breadcrumbs один размер: строка пути не меняется вместе с контролами формы.

| **Свойство** | **Значение** | **Токен уровня 2** |
|:--|:--|:--|
| Текст | 14 / 20, 400 | `typography/body/ui` |
| Цвет ссылки | — | `color/action/text/neutral/secondary/{default,hover,pressed}` |
| Цвет текущей страницы | — | `color/static/text/neutral/primary` |
| Цвет разделителя | — | `color/static/icon/neutral/tertiary` |
| Отступ вокруг разделителя | 4 | `space/inline/tight` |
| Высота строки (зона нажатия) | 24 | `size/control/s` |
| Крошки → заголовок страницы | 8 | `space/stack/default` |
| Иконка внутри элемента | 16 | `size/icon/m` |
| Кольцо фокуса | 2 плюс отступ 2 | `color/static/focus-ring/brand/default`, `space/focus-ring/offset` |

- Ссылка подчёркивается при наведении и фокусе, как обычный Link;
- Зона нажатия по вертикали — 24, это минимум WCAG 2.5.8; по горизонтали зона равна тексту, поэтому очень короткие названия («ID») дополняются отступом;
- Крошки не выделяются фоном и не образуют плашку.

## Длинный путь
Строка крошек не переносится на вторую строку и не прокручивается горизонтально на desktop.

**Сокращение имени.** Если отдельное название слишком длинное, оно обрезается многоточием, а полный текст показывается в Tooltip. Минимум видимого — около двух слов; корень и текущая страница обрезаются последними.

**Сокращение пути.** Когда уровней больше пяти или строка не помещается:

| **Шаг** | **Что показываем** |
|:--|:--|
| 1 | Корень · «…» · родитель · текущая страница |
| 2 | Если и это не помещается — корень · «…» · текущая страница |
| 3 | Если не помещается и это — только «← родитель» |

- «…» — кнопка, а не текст. Она открывает Menu со скрытыми уровнями в том же порядке;
- У кнопки есть доступное имя («Показать скрытые разделы») и *aria-expanded*;
- В меню каждый скрытый уровень — обычная ссылка; порядок сверху вниз повторяет порядок пути;
- Скрываются средние уровни: корень и родитель текущей страницы остаются видимыми всегда;
- Сворачивать путь, если уровней 3–4 и они помещаются, не нужно.

## Мобильные экраны
На узком экране полный путь не помещается и почти не используется: пользователю нужен один шаг вверх.

| **Ширина** | **Что показываем** |
|:--|:--|
| Desktop и планшет | Полный путь, при необходимости с «…» |
| Мобильный | Только «← Родительский раздел»: одна ссылка на уровень выше |

- Ссылка «назад» ведёт на **родителя по иерархии**, а не на предыдущую страницу истории;
- Стрелка «←» декоративна, название раздела — обязательный текст: «← Проекты», а не просто «Назад»;
- Разметка остаётся прежней (`nav` со списком), просто видимых элементов один;
- Горизонтальная прокрутка крошек на мобильном допустима как запасной вариант, но тогда край строки притеняется, чтобы было видно, что она продолжается.

## Состояния
| **Состояние** | **Когда** | **Оформление** |
|:--|:--|:--|
| Default | Обычная ссылка уровня | `color/action/text/neutral/secondary/default` |
| Hover | Курсор над ссылкой | `…/secondary/hover`, подчёркивание |
| Pressed | Момент нажатия | `…/secondary/pressed` |
| Focused | Клавиатурный фокус | Кольцо фокуса, подчёркивание |
| Current | Текущая страница | `color/static/text/neutral/primary`, не ссылка, курсор обычный |
| Truncated | Название не помещается | Многоточие, полный текст в Tooltip |

Состояния Disabled у крошки нет: уровень либо существует и доступен, либо не показывается.

## Поведение
| **Событие** | **Что происходит** |
|:--|:--|
| Клик по уровню | Переход на страницу этого уровня |
| Клик по текущей странице | Ничего: это не ссылка |
| Клик по «…» | Открывается Menu со скрытыми уровнями |
| Загрузка страницы | Путь известен сразу; если он приходит запросом, на его месте показывается Skeleton строки, а не пустота |
| Переход внутрь раздела | Путь удлиняется на один элемент |
| Раздел переименован | Название в крошках меняется вместе с заголовком страницы |
| Печать | Крошки печатаются: они показывают, откуда страница |

## Доступность (A11y)
- Контейнер — *nav* с доступным именем: `aria-label="Хлебные крошки"`. Слово «навигация» в имя не входит — роль уже объявлена;
- Внутри — упорядоченный список `ol` с `li`: порядок уровней имеет значение;
- Текущая страница помечается *aria-current="page"*. Если она оформлена ссылкой, атрибут остаётся на ней;
- Разделители не попадают в дерево доступности: они рисуются оформлением или помечаются `aria-hidden="true"`;
- Иконка «дом» вместо слова «Главная» получает текстовое имя;
- Обрезанное многоточием название сохраняет полный текст доступным именем ссылки: screen reader не должен читать «Догово…»;
- Кнопка «…» — обычная кнопка с именем и `aria-expanded`, её меню строится как Dropdown;
- На странице одни крошки; если рядом есть другая `nav`, у каждой своё имя;
- Цвет ссылки и текущей страницы различается не только оттенком: текущая ещё и не подчёркивается и не реагирует на наведение;
- Контраст текста ссылок ≥ 4,5 : 1, разделителя — ≥ 3 : 1 к фону (WCAG 1.4.11);
- Крошки ставятся после ссылки «к основному содержимому», а не перед ней.

## Управление клавиатурой
| **Действие** | **Результат** |
|:--|:--|
| Tab | Переводит фокус на следующий уровень пути |
| Shift + Tab | Обратный порядок |
| Enter | Переход по ссылке уровня |
| Enter / Space на «…» | Открывает меню скрытых уровней |
| ↑ / ↓ в открытом меню | Перемещение по скрытым уровням |
| Escape | Закрывает меню, фокус возвращается на «…» |

Своих стрелок у строки крошек нет: это обычные ссылки в потоке, а не составной виджет с roving tabindex.

## Regular и Inverse
| **Режим** | **Где применять** |
|:--|:--|
| Regular | Светлые и стандартные поверхности |
| Inverse | Тёмные поверхности: крошки наследуют режим фрейма, отдельного варианта нет |

## Делать
- Повторять названиями крошек заголовки соответствующих страниц;
- Держать один разделитель на всю систему;
- Делать текущую страницу не ссылкой и помечать её `aria-current="page"`;
- Сокращать середину пути, оставляя корень и родителя;
- На мобильном показывать одну ссылку на уровень выше.

## Не делать
- Не показывать историю переходов вместо иерархии;
- Не заменять крошками основную навигацию;
- Не делать крошки единственным способом вернуться;
- Не переносить путь на вторую строку;
- Не читать разделители screen reader;
- Не использовать крошки при одном уровне вложенности;
- Не помещать в крошки действия и фильтры.

## Связанные компоненты
| **Компонент** | **Когда использовать** |
|:--|:--|
| Link | Базовая ссылка, на которой строится уровень пути |
| Menu | Список скрытых уровней под «…» |
| Tabs | Панели внутри одной страницы |
| Stepper | Шаги процесса |
| Back Link | Один шаг назад, когда иерархии нет |
| Tooltip | Полный текст обрезанного названия |
| Skeleton | Путь ещё загружается |

# Решения для согласования (docs-writer 20.09.2026)
1. **Текущая страница по умолчанию показывается и не является ссылкой.** Вариант «путь заканчивается родителем» (GOV.UK) оставлен как допустимый для страниц, где H1 стоит сразу под крошками. Нужно выбрать один вариант для продукта.
2. **Разделитель — шеврон «›» по умолчанию**, косая черта — альтернатива. Знак хранится не как токен, а как значение свойства компонента: это иконка или символ, а не размер.
3. **Текст — `typography/body/ui`** (14 / 20, 400). Отдельной роли `typography/…/breadcrumb` на уровне 2 нет и заводить её не нужно: метрики совпадают с основным текстом интерфейса. Если крошки должны читаться как навигация, альтернатива — `typography/label/default` (14 / 20, 500); решает ds-architect.
4. **Цвет ссылок — `color/action/text/neutral/secondary/*`, текущей страницы — `color/static/text/neutral/primary`.** Синий цвет ссылки (`brand`) для крошек не используется: иначе путь спорит по яркости с содержимым страницы. Подчёркивание появляется на hover и фокусе.
5. **Размер один.** Ось `size` компоненту не нужна: путь не стоит в ряду с контролами. Если понадобится компактный вариант для модалки, он получит `typography/body/small` (12 / 16) — это будет отдельное решение.
6. **Сокращение включается с шестого уровня** либо раньше, если строка не помещается. Правило «корень · … · родитель · текущая» взято как основное; число видимых хвостовых уровней (1 или 2) стоит подтвердить пользователем.
7. **«…» — кнопка с меню, а не просто многоточие.** Скрытый уровень обязан оставаться достижимым: неинтерактивное многоточие лишает пользователя части пути.
8. **На мобильном — только «← Родитель».** Альтернатива (горизонтальная прокрутка полного пути) оставлена запасной: прокручиваемая строка ссылок неудобна пальцем и скрывает начало пути.
9. **Высота строки 24 (`size/control/s`)** обеспечивает минимальную зону нажатия WCAG 2.5.8 по вертикали. По горизонтали короткие названия требуют дополнительного отступа — это правило верстки, токена ему не заводим.
10. **Состояния Disabled у крошки нет**, и в каталоге компонент остаётся `interactive: true` (ссылки внутри интерактивны). Статус переведён `planned` → `doc`.
11. **Микроразметка `BreadcrumbList`** (schema.org) — вопрос фронтенда, а не дизайн-системы. Упоминаем как рекомендацию для публичных страниц, в контракт она не попадает.
