# Hint
Hint — обучающая подсказка: она привязана к элементу интерфейса, объясняет, **как им пользоваться**, и живёт на экране, пока пользователь сам не нажмёт «Далее», «Пропустить» или «Закрыть». Один Hint может быть самостоятельным (coach mark) или шагом последовательности — тура по интерфейсу.

Hint относится к семейству Tooltip: та же привязка к якорю, тот же хвостик, то же позиционирование. Отличаются назначение, способ появления и содержимое.

Документ переписан 20.09.2026 по поправке пользователя: прежняя трактовка Hint как поясняющей строки под контролом отменена (`docs/decisions.md`). Опора — WAI-ARIA APG (non-modal `dialog`), WCAG 2.2 (2.2.1 Timing Adjustable, 1.4.13 Content on Hover or Focus, 2.4.3 Focus Order, 2.1.2 No Keyboard Trap, 2.3.3 Animation from Interactions) и практика Material 3, Carbon, Atlassian, Polaris, Primer. (docs-writer 20.09.2026)

## Tooltip и Hint
| **Критерий** | **Tooltip** | **Hint** |
|:--|:--|:--|
| Назначение | Объясняет состояние элемента, даёт короткое определение, расшифровывает иконку (знак вопроса, статус) | Обучает работе с интерфейсом: онбординг, знакомство новых пользователей с функциональностью |
| Активация | Наведение, фокус или клик пользователя | Обычно инициируется системой по сценарию (тур по интерфейсу) или специальным обучающим триггером |
| Содержимое | Только короткий текст, иногда простая иконка или ссылка | Последовательность шагов («Шаг 1 из 3»), заголовки, кнопки «Далее» и «Пропустить» |
| Поведение | Исчезает, как только курсор уходит с элемента | Требует явного действия: закрыть, перейти к следующему шагу |

💡
Правило выбора: если пользователь **спросил** — это Tooltip; если система **решила рассказать** — это Hint.

## Пять компонентов сообщений: когда что
| **Задача** | **Компонент** |
|:--|:--|
| Короткое пояснение к элементу по наведению и фокусу, без интерактива | Tooltip |
| Панель по клику: произвольный контент, ссылки, поля, до двух действий | Popover |
| Сообщение обо всей странице или разделе, на всю ширину контейнера | Banner |
| Сообщение о конкретном блоке контента или форме, в потоке | Alert |
| **Обучающая подсказка: система показывает, как работает функция; шаги тура** | **Hint** |
| Постоянная поясняющая строка под полем формы | Description в Field |
| Короткое уведомление о результате действия, исчезает само | Toast |
| Задача, которая требует ответа и блокирует работу | Modal |

## Hint, Tooltip, Popover и Modal
| **Что** | **Hint** | **Tooltip** | **Popover** | **Modal** |
|:--|:--|:--|:--|:--|
| Кто начинает | Система по сценарию обучения | Пользователь: наведение или фокус | Пользователь: клик | Пользователь или система |
| Привязка | К элементу-якорю | К элементу-якорю | К триггеру | К центру экрана |
| Содержимое | Заголовок, текст, счётчик шагов, кнопки | Одна-две строки текста | Произвольное | Задача любой сложности |
| Как закрывается | Явным действием: «Далее», «Пропустить», «Закрыть», Escape | Уходом курсора и фокуса | Escape, клик вне, действие | Действием или Escape |
| Фокус | Переходит в подсказку, возвращается на якорь | Не переводится | Переходит в панель | Запирается внутри окна |
| Затемнение фона | Возможно, как часть сценария тура | Нет | Нет | Всегда |
| Сколько раз показывается | Обычно один раз на пользователя | Каждый раз по наведению | Каждый раз по клику | По необходимости |

## Использовать
- Провести нового пользователя по ключевым местам экрана (тур из 3–5 шагов);
- Показать, где появилась новая функция после обновления;
- Объяснить неочевидный элемент, который пользователь ещё ни разу не открывал;
- Подсказать следующий шаг в сценарии настройки продукта;
- Обратить внимание на элемент, который пользователь ищет и не находит.

## Не использовать
| **Задача** | **Компонент** |
|:--|:--|
| Пояснение по запросу пользователя: наведение или фокус | Tooltip |
| Панель с содержимым и действиями, открытая по клику | Popover |
| Постоянная поясняющая строка под полем | Description в Field |
| Ошибка, предупреждение, успех в форме или блоке | Alert · Validation Message в Field |
| Сообщение о странице, сервисе, тарифе | Banner |
| Результат действия пользователя | Toast |
| Задача, которая блокирует работу до ответа | Modal |
| Пустой раздел: рассказать, с чего начать | Empty State |
| Длинное обучение: статья, видео, чек-лист | Страница справки · Drawer |

Hint — не способ передать важную информацию: пользователь имеет право пропустить обучение и никогда его не увидеть. Всё, без чего нельзя работать, живёт в интерфейсе.

## Состав
| **Элемент** | **Назначение** | **Входит в компонент** |
|:--|:--|:--|
| Контейнер | Поверхность подсказки: фон, скругление, тень | Да |
| Заголовок | Название шага, 1 строка | Да, опционально |
| Текст | Объяснение, 1–3 строки | Да |
| Счётчик шагов | «Шаг 1 из 3» или точки-индикаторы | Да, опционально |
| Кнопки «Далее» / «Назад» | Переход по шагам тура | Да, опционально |
| «Пропустить» | Выход из тура целиком | Да, опционально |
| Кнопка закрытия | Закрывает подсказку без продолжения | Да, опционально |
| Хвостик (Tail) | Указывает на якорь | Да, опционально |
| Медиа | Картинка или короткая gif над текстом | Да, опционально |
| Подсветка якоря (spotlight) | Выделяет элемент, о котором идёт речь | Нет — слой сценария тура |
| Затемнение фона (scrim) | Гасит остальной интерфейс вокруг подсветки | Нет — слой сценария тура |
| Маячок (beacon) | Пульсирующая точка: приглашает открыть подсказку | Нет — отдельный компонент-триггер |
| Очередь шагов и правило показа | Какой шаг за каким, сколько раз показывать | Нет — логика продукта |

**Граница компонента.** Hint — это панель у якоря. Подсветка, затемнение и маячок — отдельные слои и отдельные компоненты: их используют и другие сценарии, а тур может работать вообще без них.

## Размеры
У Hint нет оси размера контрола: размер задаётся шириной панели.

| **Ширина** | **Значение** | **Токен уровня 2** | **Где применять** |
|:--|:--|:--|:--|
| S | 240 | `size/overlay/width-compact` | Подсказка в одну фразу, узкая панель у иконки |
| M | 320 | `size/overlay/width` | Стандарт: заголовок, текст, счётчик и кнопки |

| **Свойство** | **Значение** | **Токен уровня 2** |
|:--|:--|:--|
| Заголовок | 16 / 24, 600 | `typography/heading/subsection` |
| Текст | 14 / 20, 400 | `typography/body/ui` |
| Счётчик шагов | 12 / 16, 400 | `typography/helper/default` |
| Внутренний отступ | 16 (решение, токена нет) | см. «Решения для согласования» |
| Заголовок ↔ текст | 4 | `space/stack/tight` |
| Текст ↔ кнопки | 16 | `space/stack/loose` |
| Скругление | 8 | `radius/popover` |
| Тень | 0 · 8 · 16 · −2 | `shadow/popover/*` |
| Хвостик: основание и вылет | 8 · 4 | `size/overlay/arrow`, `size/overlay/arrow-depth` |
| Зазор до якоря (до острия хвостика) | 4 | `space/overlay/offset` |
| Слой панели | 1500 | `z-index/popover` |
| Слой затемнения | 1400 | `z-index/overlay` |

Высота — по содержимому. Панель не прокручивается: если текст не помещается, шаг нужно разделить.

## Содержимое
- Тур — 3–5 шагов. Длиннее пользователь не проходит;
- Один шаг — одна мысль: что это за элемент и зачем он нужен;
- Заголовок до 1 строки, текст до 3 строк;
- Счётчик обязателен, если шагов больше одного: пользователь должен видеть, сколько осталось;
- Кнопки: основная «Далее» (на последнем шаге — «Готово»), второстепенная «Назад», текстовая «Пропустить»;
- «Пропустить» видно на каждом шаге, а не только на первом;
- Не пишите «Нажмите сюда»: подсказка объясняет, а не командует;
- Текст не повторяет подпись элемента, на который указывает.

## Состояния
| **Состояние** | **Когда** | **Поведение** |
|:--|:--|:--|
| Idle | Обучение ещё не начато или отложено | На экране ничего нет или горит маячок |
| Active | Шаг показан | Панель видна, фокус внутри, якорь подсвечен |
| Paused | Якорь исчез, ушёл из вида или экран перестроился | Панель скрыта, тур ждёт возвращения якоря |
| Completed | Пройден последний шаг | Тур закрывается и больше не запускается |
| Skipped | Пользователь нажал «Пропустить» | Тур закрывается целиком, запустить его можно из справки |
| Dismissed | Пользователь закрыл один шаг крестиком или Escape | Закрывается текущий шаг; продолжение — по правилу продукта |

У самой панели нет Hover, Pressed, Disabled: состояния принадлежат кнопкам внутри.

## Варианты и роли
- **Ролей (info · success · warning · danger) у Hint нет.** Обучение нейтрально: поверхность `color/layer/popover/neutral/default`. Сообщение со статусом — это Alert или Banner;
- **Одиночный Hint и шаг тура** — одно и то же тело; отличие в том, есть ли счётчик и кнопки навигации;
- **С подсветкой и без** — свойство сценария, а не роль;
- **С маячком и без** — свойство триггера;
- **Позиция** — сторона (top · bottom · left · right) и выравнивание (start · center · end), 12 комбинаций, как у Tooltip и Popover;
- **Инверсный вид** — режим dark на фрейме, отдельных токенов нет.

## Поведение
### Очередь шагов
| **Событие** | **Что происходит** |
|:--|:--|
| Тур запущен | Показывается первый шаг; остальные не отрисовываются |
| «Далее» | Текущий шаг закрывается, следующий открывается у своего якоря, счётчик обновляется |
| «Назад» | Возврат к предыдущему шагу без потери прогресса |
| «Пропустить» | Тур закрывается целиком, прогресс сохраняется как «пропущен» |
| Последний шаг, «Готово» | Тур помечается пройденным |
| Escape | Закрывается текущий шаг; тур считается отложенным, а не пройденным |
| Клик вне панели | По умолчанию ничего не происходит: тур закрывается только явным действием |

### Якорь вне экрана
| **Ситуация** | **Что делает Hint** |
|:--|:--|
| Якорь есть, но он ниже или выше видимой области | Страница плавно прокручивается к якорю, после чего открывается шаг |
| Якорь внутри свёрнутой панели, вкладки или меню | Сценарий тура сам открывает контейнер; если это невозможно, шаг пропускается |
| Якоря нет в этой сборке или у этой роли нет доступа | Шаг пропускается, счётчик пересчитывается: «Шаг 2 из 3», а не «2 из 4» |
| Якорь исчез, пока шаг открыт | Тур переходит в Paused: панель скрывается, а не висит над пустым местом |
| Экран стал узким, раскладка перестроилась | Позиция пересчитывается; панель S разворачивается в нижнюю панель на всю ширину |

### Правило показа
- Тур показывается **один раз на пользователя**: результат (пройден · пропущен · отложен) сохраняется на стороне продукта;
- Отложенный тур можно продолжить: точка входа — пункт «Обучение» в справке или маячок у элемента;
- Тур не запускается поверх незавершённой задачи: если открыта модалка, форма в состоянии ошибки или идёт загрузка, обучение ждёт;
- Одновременно на экране только одна обучающая подсказка;
- Новый тур после обновления продукта — отдельный сценарий с собственной отметкой о показе.

### Движение
- Появление и переход между шагами — короткая анимация (`motion/duration/dropdown` = 200);
- Пульсация маячка повторяется, поэтому обязана останавливаться по `prefers-reduced-motion: reduce` (WCAG 2.3.3);
- При `reduce` подсветка остаётся статичной обводкой, прокрутка к якорю делается мгновенной;
- Никаких автотаймеров: шаг не сменяется и не закрывается сам (WCAG 2.2.1).

## Regular и Inverse
| **Режим** | **Где применять** |
|:--|:--|
| Regular | Светлые и стандартные поверхности |
| Inverse | Тёмные поверхности: подсказка наследует режим фрейма, отдельного варианта нет |

Затемнение фона (scrim) от режима не зависит: оно одинаково гасит интерфейс в обеих темах.

## Доступность (A11y)
- Панель — **non-modal dialog**: *role="dialog"* и доступное имя через *aria-labelledby* на заголовок (или *aria-label*, если заголовка нет);
- При открытии шага фокус переводится в панель: на заголовок с `tabindex="-1"` или на первую кнопку. Пользователь клавиатуры и screen reader попадают туда же, куда смотрит зрячий пользователь;
- **Escape закрывает подсказку и возвращает фокус на якорь** — на элемент, о котором шла речь, а не в начало страницы;
- Порядок Tab внутри панели: заголовок → текст-ссылки → «Назад» → «Далее» → «Пропустить» → «Закрыть». Фокус не запирается (WCAG 2.1.2), но и не теряется: выход Tab'ом за пределы панели возвращает фокус на якорь;
- Смена шага объявляется: у панели меняется доступное имя, фокус переводится в новый шаг заново. Счётчик «Шаг 2 из 3» входит в текст, а не только в подпись;
- Затемнение фона не должно делать остальной интерфейс «кликабельным, но не читаемым»: если фон погашен, он недоступен и для указателя, и для клавиатуры, а выход — «Пропустить» и Escape;
- Подсветка якоря не перекрывает сам элемент и не снижает его контраст;
- Тур не запускается автоматически у пользователя, который его уже прошёл или пропустил;
- Автотаймеров нет (WCAG 2.2.1); анимации подчиняются `prefers-reduced-motion` (WCAG 2.3.3);
- Панель не перекрывает якорь (WCAG 1.4.13, «не заслоняет») и не открывается по наведению;
- Контраст текста ≥ 4,5 : 1, иконок, обводки подсветки и маячка ≥ 3 : 1 (WCAG 1.4.3, 1.4.11);
- Кнопка закрытия получает доступное имя «Закрыть», зона нажатия не меньше 24 × 24 (WCAG 2.5.8);
- Маячок — кнопка с доступным именем («Показать подсказку»), а не декоративная точка.

## Управление клавиатурой
| **Действие** | **Результат** |
|:--|:--|
| Enter / Space на маячке | Открывает подсказку, фокус переходит внутрь |
| Tab / Shift + Tab внутри панели | Перемещает фокус по кнопкам и ссылкам шага |
| Tab за пределы панели | Возвращает фокус на якорь, шаг остаётся открытым |
| Enter / Space на «Далее» | Открывает следующий шаг, фокус переходит в него |
| Enter / Space на «Назад» | Возвращает предыдущий шаг |
| Enter / Space на «Пропустить» | Закрывает тур, фокус возвращается на якорь текущего шага |
| Escape | Закрывает текущий шаг, фокус возвращается на якорь |

Стрелки для перехода по шагам не используются: это не список и не набор вкладок.

## Делать
- Держать тур коротким: 3–5 шагов;
- Показывать счётчик и «Пропустить» на каждом шаге;
- Прокручивать страницу к якорю перед показом шага;
- Пропускать шаг, если его элемента нет, и пересчитывать счётчик;
- Возвращать фокус на якорь при закрытии;
- Давать способ вернуться к обучению позже.

## Не делать
- Не запускать тур поверх незавершённой задачи и поверх модалки;
- Не закрывать шаг по таймеру и не листать шаги автоматически;
- Не прятать в обучение информацию, без которой нельзя работать;
- Не показывать два тура одновременно;
- Не повторять пройденный или пропущенный тур при каждом входе;
- Не подменять Hint'ом Tooltip: подсказка по наведению — это Tooltip;
- Не оставлять пульсацию маячка при `prefers-reduced-motion: reduce`.

## Связанные компоненты
| **Компонент** | **Когда использовать** |
|:--|:--|
| Tooltip | Пользователь сам спросил: подсказка по наведению или фокусу |
| Popover | Панель с содержимым и действиями, открытая по клику |
| Modal | Задача блокирует работу до ответа |

| Button, Link | Кнопки шага: «Далее», «Назад», «Пропустить» |

# Решения для согласования (docs-writer 20.09.2026)
1. **Документ переписан: Hint — обучающая подсказка семейства Tooltip.** Прежняя редакция (Hint = поясняющая строка, близкая к Description в Field) отменена пользователем 20.09.2026. Из документа убраны размеры S · M · L по высоте контрола, токены `typography/field/hint/*` и `size/field/hint-icon/*` из экспорта: они относятся к **Description внутри Field**, а не к этому компоненту, и остаются за `field`.
2. **Границы компонента: панель у якоря.** Подсветка (spotlight), затемнение (scrim) и маячок (beacon) — отдельные слои сценария тура, а не части Hint. Маячок предлагается вынести в отдельный компонент-триггер: он нужен и вне обучения.
3. **Две ширины: S 240 (`size/overlay/width-compact`) и M 320 (`size/overlay/width`).** Ширина L (400) не предлагается: если шаг требует такой панели, его нужно разделить.
4. **Внутренний отступ 16** — тот же открытый вопрос, что у Popover: существующий `space/overlay/popover-padding` = 8 описан для панели-обёртки. Нужен либо общий `space/overlay/popover-content-padding` = 16, либо отдельный шаг для обучающих панелей.
5. **Escape закрывает шаг и считает тур отложенным, «Пропустить» — пройденным-пропущенным.** Разница важна для правила повторного показа.
6. **Клик вне панели ничего не делает.** В отличие от Popover, обучающий шаг закрывается только явным действием — иначе пользователь теряет тур случайным кликом.
7. **Шаг с отсутствующим якорем пропускается, счётчик пересчитывается.** Альтернатива (показать шаг по центру экрана без якоря) отклонена: подсказка без привязки — это уже Modal.
8. **Тур показывается один раз на пользователя**, отметка о показе — на стороне продукта, не в компоненте.
