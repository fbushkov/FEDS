# Accordion
Accordion — вертикальный набор секций одного уровня, у каждой из которых есть заголовок-кнопка и скрытая панель содержимого. Нажатие на заголовок раскрывает или сворачивает свою панель; остальная страница при этом сдвигается вниз.

Документа пользователя по Accordion нет: текст написан по WAI-ARIA APG (`accordion`, `disclosure`), WCAG 2.2 (2.3.3 Animation from Interactions, 4.1.3 Status Messages, 2.5.8 Target Size, 1.4.11 Non-text Contrast) и практике Material, Carbon, Atlassian, Polaris, Primer, GOV.UK. Свои числа и решения собраны в разделе «Решения для согласования». (docs-writer 20.09.2026)

| **Часть** | **Назначение** |
|:--|:--|
| Accordion | Контейнер: список секций, общие разделители и правило раскрытия |
| Accordion Item | Одна секция: заголовок и панель |
| Header | Строка-кнопка целиком: заголовок, иконка-стрелка, дополнения |
| Title | Название секции |
| Chevron | Иконка-стрелка, показывает состояние секции |
| Panel | Скрываемое содержимое секции |
| Divider | Линия между секциями |

💡
Аккордеон — способ сократить длинную страницу, а не спрятать сложность. Содержимое, которое нужно всем, не убирают под заголовок: свёрнутый текст не находится поиском по странице, не попадает в печать и часть пользователей его просто не открывает (наблюдение исследований GOV.UK).

## Раскрытие и структура: когда что
| **Задача** | **Компонент** |
|:--|:--|
| **Несколько секций одного уровня, пользователь читает их по очереди** | **Accordion** |
| Один самостоятельный блок «Показать подробности» | Disclosure |
| Взаимоисключающие панели рядом друг с другом, переключение без сдвига страницы | Tabs |
| Секции нужны все и сразу, читаются сверху вниз | Обычные секции с заголовками |
| Длинный текст с оглавлением | Страница + якоря |
| Строка таблицы с подробностями | Expandable Row |
| Содержимое всплывает поверх интерфейса | Popover / Modal |

## Использовать
- Часто задаваемые вопросы и справочные разделы;
- Дополнительные и необязательные параметры формы: «Расширенные настройки», «Реквизиты»;
- Длинную страницу, разбитую на 3–8 названных секций, из которых обычно нужна одна;
- Список объектов, где у каждого есть подробности: заказ, задача, запись журнала;
- Мобильную раскладку, где содержимое не помещается на экран целиком.

## Не использовать
| **Задача** | **Компонент** |
|:--|:--|
| Секция ровно одна | Disclosure |
| Секций больше 8–10 | Отдельные страницы / Sidebar |
| Содержимое нужно сравнивать между секциями | Обычные секции |
| Важная информация: цена, условия, предупреждение | Текст на странице / Alert |
| Обязательные поля формы | Секция формы без раскрытия |
| Шаги процесса с порядком | Stepper |
| Переключение панелей без сдвига страницы | Tabs |

## Accordion, Disclosure и Tabs
| **Признак** | **Disclosure** | **Accordion** | **Tabs** |
|:--|:--|:--|:--|
| Сколько блоков | Один самостоятельный | Группа секций одного уровня | Группа панелей одного уровня |
| Разметка | `button` + `aria-expanded` | `heading` + `button` + `aria-expanded`, панель — `region` | `tablist` + `tab` + `tabpanel` |
| Сколько открыто | 0 или 1 | 0, 1 или все — по правилу компонента | Ровно одна |
| Направление | Содержимое разворачивается вниз | Содержимое разворачивается вниз | Содержимое меняется на месте |
| Стрелки клавиатуры | Не нужны | Опционально между заголовками | Обязательны |
| Что происходит со страницей | Сдвигается вниз | Сдвигается вниз | Высота не меняется |
| Когда выбирать | «Показать подробности» под полем | Раздел FAQ, набор настроек | «Обзор / Участники / История» |

**Accordion — это группа Disclosure с общей рамкой и общим правилом раскрытия.** Если секция одна, не заводите аккордеон из одного элемента.

## Одиночное и множественное раскрытие
| **Режим** | **Как работает** | **Когда применять** |
|:--|:--|:--|
| Множественное (по умолчанию) | Пользователь открывает сколько угодно секций, они не закрывают друг друга | FAQ, настройки, любые секции, которые сравнивают |
| Одиночное | Открытие секции закрывает предыдущую | Длинные панели, мастера, мобильные экраны, где видна лишь одна секция |

- **По умолчанию — множественное.** Самозакрывающаяся секция ломает ожидание: пользователь открыл две, вернулся — одной нет;
- Одиночный режим применяется, только когда панели длинные и открытые сразу две не помещаются на экран;
- В одиночном режиме допустимо состояние «ничего не открыто»: обязательного выбора у аккордеона нет;
- Кнопка «Раскрыть все / Свернуть все» ставится над списком, если секций больше четырёх (приём GOV.UK). В одиночном режиме её не бывает;
- Состояние «раскрыть все» помнится в пределах сессии; отдельные секции — по желанию продукта;
- Первая секция может быть раскрыта по умолчанию, если её содержимое нужно почти всем. Раскрывать по умолчанию все секции нет смысла — это обычные секции.

## Заголовок-кнопка
- Заголовок целиком — кнопка: нажатие работает по всей строке, а не только по стрелке;
- Кнопка обёрнута в элемент заголовка нужного уровня (`h2`…`h4`) — без него screen reader теряет структуру страницы;
- Уровень заголовка соответствует месту секции в документе и одинаков у всех секций аккордеона;
- Текст заголовка отвечает на вопрос «что внутри» — существительное или вопрос пользователя, не «Подробнее»;
- Заголовок не переносится более чем на две строки; многоточие не используется — текст переносится;
- В строке заголовка допускаются: Leading Icon, счётчик (Badge), статус (Status), дополнительная метка справа. Кнопок внутри строки быть не должно: вложенная кнопка внутри кнопки — недопустимая разметка. Если действие нужно, оно выносится в панель или в отдельную строку рядом с заголовком, за пределы кнопки;
- Минимальная высота строки заголовка — зона нажатия не меньше 24 × 24 (WCAG 2.5.8); фактически строка идёт во всю ширину контейнера.

## Иконка-стрелка
- Стрелка показывает состояние, а не действие: свёрнутая секция — стрелка вниз, раскрытая — вверх;
- Поворот на 180° за то же время, что раскрытие панели (`motion/duration/expand`, 200);
- Положение стрелки — свойство компонента: справа (по умолчанию, для текстовых секций во всю ширину) или слева перед заголовком (для списков и вложенных структур, где важно видеть уровень). В одном экране положение одно;
- Иконка декоративна и помечается `aria-hidden="true"`: состояние передаётся через `aria-expanded`, а не через стрелку;
- Цвет — `color/static/icon/neutral/secondary`, размер `size/icon/{m,l}` (16 · 20);
- Знак «плюс / минус» вместо стрелки не используется: «плюс» читается как «добавить».

## Размеры и геометрия
Accordion поддерживает два размера: S (плотный) и M (стандартный).

| **Свойство** | **S · M** | **Токен уровня 2** |
|:--|:--|:--|
| Отступ строки заголовка по вертикали | 12 · 16 | `space/card/padding-compact` · `space/card/padding` |
| Отступ по горизонтали | 12 · 16 | `space/card/padding-compact` · `space/card/padding` |
| Заголовок | 14 / 20 · 16 / 24, 600 | `typography/heading/group` · `typography/heading/subsection` |
| Текст панели | 14 / 20 · 16 / 24 | `typography/body/ui` · `typography/body/reading` |
| Заголовок ↔ стрелка | 8 · 12 | `space/inline/default` · `space/control/gap/m` |
| Разделитель | 1 | `border/width/divider` + `color/static/divider/neutral/default` |
| Скругление (вариант «карточки») | 12 | `radius/card` |
| Промежуток между карточками | 8 | `space/stack/default` |

Высота строки заголовка не фиксируется числом: она равна интерлиньяжу заголовка плюс отступы, поэтому длинный заголовок в две строки не обрезается.

## Разделители и вид
| **Вид** | **Как выглядит** | **Где применять** |
|:--|:--|:--|
| Flush (по умолчанию) | Секции идут вплотную, между ними линия 1; фона и скруглений нет | Текстовые разделы, FAQ, содержимое страницы |
| Boxed | Общая рамка вокруг всего списка, линии между секциями | Настройки, блоки внутри карточки |
| Cards | Каждая секция — отдельная карточка с фоном, скруглением и промежутком 8 | Списки объектов, мобильные экраны |

- Линия ставится **между** секциями; верхняя и нижняя границы списка — только в вариантах Boxed и Cards;
- Раскрытая секция может получать слабую подсветку заголовка (`color/action/bg/neutral/ghost/selected`), но не обязана: состояние уже передаёт стрелка;
- Линия не разрывается между заголовком и его панелью: панель зрительно принадлежит заголовку сверху.

## Состояния
| **Состояние** | **Когда** | **Оформление** |
|:--|:--|:--|
| Collapsed | Панель скрыта | Заголовок `color/static/text/neutral/primary`, стрелка вниз |
| Expanded | Панель показана | Стрелка вверх, панель в потоке |
| Hover | Курсор над строкой заголовка | Фон `color/action/bg/neutral/ghost/hover` на всю строку |
| Pressed | Момент нажатия | Фон `color/action/bg/neutral/ghost/pressed` |
| Focused | Клавиатурный фокус | Кольцо `color/static/focus-ring/brand/default` вокруг строки заголовка |
| Disabled | Секция недоступна | Заголовок и стрелка `…/neutral/disabled`, панель не раскрывается |

**Disabled.** Недоступная секция — редкий и почти всегда неудачный случай: пользователь видит заголовок, но не может узнать, что внутри.

- Лучше раскрывать секцию и объяснять внутри, почему данных нет (Empty State) или почему действие недоступно;
- Если состояние всё же нужно, заголовок помечается `aria-disabled="true"` и **остаётся фокусируемым**: атрибут `disabled` убрал бы заголовок из порядка чтения и лишил пользователя объяснения;
- Рядом с недоступным заголовком нужна причина: короткая подпись или Tooltip;
- Раскрытую секцию нельзя делать недоступной: сначала сворачиваем, потом блокируем.

## Вложенность
Вложенный аккордеон внутри панели аккордеона **не используется**.

| **Почему** | **Что делать** |
|:--|:--|
| Пользователь теряет уровень: два ряда стрелок выглядят одинаково | Разделить содержимое на страницы или добавить Tabs внутри панели |
| Каждое раскрытие сдвигает страницу дважды, содержимое «убегает» из-под курсора | Оставить один уровень |
| Заголовки конфликтуют по уровням (`h3` внутри `h3`) | Пересобрать иерархию раздела |
| Клавиатурой приходится проходить оба уровня | Упростить структуру |

Если второй уровень неизбежен, он допускается ровно один, с отступом слева и другим размером заголовка; третий уровень запрещён. Список, в котором у каждой строки есть подробности, лучше строить как Expandable Row таблицы, а не как аккордеон в аккордеоне.

## Анимация раскрытия
| **Правило** | **Значение** |
|:--|:--|
| Длительность раскрытия и сворачивания | `motion/duration/expand` (200) |
| Что анимируется | Высота панели и поворот стрелки; содержимое не выезжает отдельно |
| Прокрутка | Страница не прокручивается сама; при раскрытии нижней секции допустима доводка, чтобы заголовок остался виден |
| Длинная панель | Анимация высоты отключается, панель появляется сразу: плавный рост экрана на тысячу пикселей выглядит как зависание |
| `prefers-reduced-motion: reduce` | Раскрытие мгновенное (`motion/duration/instant`), поворот стрелки без перехода (WCAG 2.3.3) |

Сворачивание идёт с той же длительностью, что раскрытие: разная скорость читается как сбой.

## Поведение
| **Событие** | **Что происходит** |
|:--|:--|
| Клик по заголовку | Секция раскрывается или сворачивается |
| Переход по якорю на секцию | Секция раскрывается и прокручивается в видимую область |
| Поиск по странице | Браузер, поддерживающий `hidden="until-found"`, раскрывает секцию с найденным текстом; там, где поддержки нет, поиск содержимое не находит |
| Печать | Все секции раскрываются |
| Ошибка валидации внутри свёрнутой секции | Секция раскрывается автоматически, фокус переходит на первое поле с ошибкой |
| Перезагрузка страницы | Состояние секций не обязано сохраняться; если сохраняется, то в пределах сессии |
| Изменение ширины окна | Раскрытые секции остаются раскрытыми |

## Доступность (A11y)
- Заголовок секции — `button` внутри элемента заголовка (`h2`…`h4`), без лишних оболочек между ними;
- Кнопка несёт *aria-expanded* (`true` / `false`) и *aria-controls* с `id` панели;
- Панель получает `role="region"` и *aria-labelledby* на кнопку — но только если секций немного: у длинного списка десятки регионов засоряют навигацию по ориентирам (примечание WAI-ARIA APG);
- Скрытая панель скрывается атрибутом `hidden`, а не нулевой высотой с видимым содержимым: иначе фокус попадает внутрь свёрнутой секции;
- Стрелка декоративна (`aria-hidden="true"`), состояние читается из `aria-expanded`;
- Уровни заголовков не пропускаются и не подбираются «по размеру шрифта»;
- Кольцо фокуса рисуется вокруг всей строки заголовка и видно на любом фоне;
- Недоступная секция — *aria-disabled="true"*, фокусируемая;
- Раскрытие не объявляется в live-region: `aria-expanded` уже сообщает результат;
- Разделители декоративны и скрываются от screen reader;
- Стрелка и подсветка заголовка держат ≥ 3 : 1 к фону (WCAG 1.4.11).

## Управление клавиатурой
| **Действие** | **Результат** |
|:--|:--|
| Tab | Переводит фокус на следующий заголовок; из раскрытого заголовка — в его панель |
| Shift + Tab | Обратный порядок |
| Enter / Space | Раскрывает или сворачивает секцию под фокусом |
| ↑ / ↓ | Перемещает фокус между заголовками аккордеона (опционально, по APG) |
| Home / End | Первый / последний заголовок (опционально) |

- Стрелки перемещают фокус только между заголовками и не раскрывают секции;
- Внутри панели стрелки работают как обычно — прокрутка и содержимое;
- Порядок Tab совпадает с порядком на экране: заголовок → его панель → следующий заголовок.

## Адаптив
- На мобильном аккордеон — основной способ уместить длинную страницу; вид Cards удобнее, чем Flush;
- Строка заголовка занимает всю ширину, стрелка прижата к правому краю;
- На мобильном чаще выбирают одиночное раскрытие: две открытые панели не помещаются;
- Вкладки на мобильном можно разворачивать в аккордеон — это допустимая замена (`tabs.md`, «Адаптив»);
- Отступы уменьшаются до размера S, размер шрифта — нет.

## Делать
- Называть секции так, чтобы было понятно, что внутри;
- Оставлять множественное раскрытие по умолчанию;
- Раскрывать секцию, если в ней ошибка валидации или на неё ведёт якорь;
- Держать один уровень секций;
- Отключать анимацию по `prefers-reduced-motion`.

## Не делать
- Не прятать в аккордеон важное: цены, условия, предупреждения;
- Не вкладывать аккордеон в аккордеон;
- Не ставить кнопки и ссылки внутрь строки-заголовка;
- Не закрывать секцию, которую пользователь открыл, без его действия;
- Не использовать «плюс / минус» вместо стрелки;
- Не делать аккордеон из одной секции;
- Не анимировать раскрытие очень длинной панели.

|:--|:--|
| Tabs | Взаимоисключающие панели без сдвига страницы |
| Disclosure | Один самостоятельный блок «Показать подробности» |

# Решения для согласования (docs-writer 20.09.2026)
1. **Множественное раскрытие — режим по умолчанию.** Одиночное включается свойством, когда панели длинные. Это выбор системы: APG допускает оба, Carbon и Atlassian по умолчанию разрешают несколько открытых секций.
2. **Два размера, S и M, а не три.** Аккордеон — блок содержимого, а не контрол в одном ряду с Button и Input, поэтому шкала `size/control/*` к нему не применяется, высота строки растёт от текста. Если ds-architect решит иначе, добавится L с `space/section/padding` (24).
3. **Отступы берутся у карточки** — `space/card/padding` (16) и `space/card/padding-compact` (12). Новые имена вида `space/accordion/header-padding` не заводятся: у секции тот же ритм, что у карточки, а второго потребителя у нового имени нет.
4. **Заголовок — `typography/heading/{group,subsection}`** (14 / 20 / 600 и 16 / 24 / 600). Альтернатива `typography/label/default` (500) отклонена: заголовок секции участвует в структуре документа и должен читаться как заголовок.
5. **Стрелка справа по умолчанию**, слева — свойство для вложенных структур и списков. Положение — свойство компонента, а не ось: цвета и размеры от него не зависят.
6. **Кнопок внутри строки-заголовка нет.** Технический запрет (кнопка внутри кнопки), а не вкусовое ограничение; действия переезжают в панель.
7. **Вложенность запрещена**, допускается ровно один дополнительный уровень в безвыходной ситуации. Требуется подтверждение пользователя: если вложенные аккордеоны в продукте уже есть, решение надо принимать явно.
8. **Disabled сохраняем, но с оговоркой**: `aria-disabled` вместо `disabled`, обязательная причина рядом. Альтернатива — вовсе убрать состояние из компонента; решает пользователь.
9. **`motion/duration/expand` (200) используется как есть** — описание токена прямо называет аккордеон. Новых длительностей не требуется. Кривой ускорения на уровне 2 нет вообще (группа `motion/easing/*` отсутствует, см. `docs/decisions.md` от 20.09.2026): пока раскрытие описывается только длительностью.
10. **`role="region"` на панель — только при небольшом числе секций** (ориентир — до 6). Это прямая оговорка APG, и её стоит зафиксировать правилом, а не оставлять на усмотрение разработчика.
11. **В каталоге снимается флаг `hidden`.** Он стоял с 19.09.2026, когда в плагине показывали только простые компоненты; после появления документа запись ведёт себя как `popover` и `banner`, с которых флаг уже снят. Статус `planned` → `doc`.
12. **Accordion пока не помечается `kind: "block"`.** По записи от 20.09.2026 аккордеон был в списке кандидатов в блоки; решение за пользователем. Довод за блок: секция собирается из заголовка, стрелки, разделителя и произвольного содержимого. Довод против: сам по себе аккордеон не содержит других базовых компонентов обязательно — Badge и Status в заголовке опциональны.
