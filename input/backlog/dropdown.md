# Dropdown
💡 **Dropdown — механика, а не отдельный компонент** (решение автора 21.09.2026): это список внутри Select, Combobox и Multiselect. В каталоге плагина не выбирается отдельно; в Figma — приватные части `_ Select / Dropdown` и `_ Select / Dropdown Items`. Архитектура — `docs/forms-architecture.md`.

Dropdown и Dropdown Item — общая база выпадающего списка. На ней строятся Select, Combobox и Multiselect, позже — Menu и Autocomplete. (добавлено docs-writer 19.09.2026)

Разделы «Dropdown» и «Dropdown Item» перенесены из `select.md` без изменений. Всё, что добавлено для других потребителей, помечено «(добавлено docs-writer 19.09.2026)». (добавлено docs-writer 19.09.2026)

| **Часть** | **Назначение** |
|:--|:--|
| Dropdown | Контейнер со списком вариантов |
| Dropdown Item | Отдельный вариант, заголовок группы или разделитель |

💡
Dropdown не существует сам по себе: его всегда открывает контрол-владелец — Select Button, поле Combobox или Multiselect. Label, Description и текст валидации относятся к Field владельца, а не к списку. (добавлено docs-writer 19.09.2026)

## Потребители (добавлено docs-writer 19.09.2026)
| **Компонент** | **Режим выбора** | **Индикатор выбора** | **Особенности списка** |
|:--|:--|:--|:--|
| Select | single | Check Indicator (опционально) | Пункт «Все / Любой / Неважно», Placeholder не пункт списка |
| Combobox | single | Check Indicator (опционально) | Фильтрация по вводу, подсветка совпадения, «Создать …», асинхронная загрузка |
| Multiselect | multi | Checkbox | «Выбрать все», список не закрывается после выбора |
| Menu (план) | действие, без выбора | Нет или Check для пунктов-настроек | Роль menu, а не listbox — см. «Решения для согласования» |
| Autocomplete (план) | подсказки к вводу | Нет | Список предложений к свободному тексту |

## Figma (добавлено docs-writer 19.09.2026)
- В библиотеке Dropdown и Dropdown Item — приватные компоненты `_Dropdown` и `_Dropdown Item`. Они не публикуются: дизайнер берёт готовые Select, Combobox или Multiselect, внутри которых они уже собраны.
- Варианты `_Dropdown Item` задаются свойствами: тип (Value · Group Title · Divider), режим выбора (single · multi), размер (S · M · L), состояние, Selected (да · нет), Leading Icon, Description.
- Публиковать ли Dropdown Item для Menu — вопрос в «Решениях для согласования».

## Размеры (добавлено docs-writer 19.09.2026)
Dropdown и Dropdown Item поддерживают размеры S / M / L. Размер списка всегда равен размеру контрола-владельца: у Select M — Dropdown M и Dropdown Item M. Смешивать размеры нельзя.

# Dropdown
Dropdown появляется поверх интерфейса и содержит варианты выбора.
## Размер и расположение
- Dropdown не должен быть уже Select Button;
- Если требуется больше места для названий, Dropdown может быть шире;
- Обычно список открывается вниз;
- Если места снизу недостаточно, открывается вверх;
- Dropdown не меняет размеры Select Button;
- Клик за пределами Dropdown закрывает его без изменения значения.

### Позиционирование для всех потребителей (добавлено docs-writer 19.09.2026)
Правила выше сформулированы для Select Button. Для остальных потребителей вместо Select Button подставляется контрол-владелец: поле Combobox или поле Multiselect.
- Dropdown выравнивается по начальному (левому) краю владельца. Если Dropdown шире и выходит за правый край viewport, он выравнивается по правому краю владельца;
- Между владельцем и Dropdown сохраняется фиксированный зазор. Значение задаёт токен уровня 2, его определяет ds-architect;
- При открытии вверх порядок пунктов не переворачивается: первый пункт остаётся сверху;
- Dropdown не перекрывает свой контрол-владелец: пользователь продолжает видеть значение или вводимый текст;
- При прокрутке страницы Dropdown остаётся привязан к владельцу. Если владелец ушёл из viewport, список закрывается;
- Открытый Dropdown не должен закрывать элемент в фокусе (WCAG 2.2, 2.4.11 Focus Not Obscured).

## Количество вариантов и Scroll
По спецификации:
- До 10 вариантов можно показывать без внутреннего Scroll;
- Если вариантов больше 10, Dropdown становится прокручиваемым;
- При прокрутке Dropdown страница под ним не должна прокручиваться вслед за достижением края списка.

Если список регулярно становится значительно длиннее, рассмотрите Combobox.

### Scroll: уточнения (добавлено docs-writer 19.09.2026)
- Максимальная высота Dropdown равна высоте 10 пунктов Value текущего размера плюс внутренние отступы контейнера. Group Title и Divider занимают место в этой высоте;
- Закреплённые элементы не прокручиваются вместе со списком: поле поиска в Multiselect и пункт «Выбрать все» — сверху, пункт «Создать …» — снизу;
- При навигации клавиатурой Active Item всегда прокручивается в видимую область;
- Если места в viewport меньше, чем нужно для 10 пунктов, высота уменьшается до доступной, Scroll сохраняется.

## Empty
- Если доступных вариантов нет, вместо пустого контейнера показывайте сообщение: **«Ничего не найдено»** или другое контекстное Empty-состояние.
- Не показывайте одновременно Empty и Dropdown Item.

### Empty: уточнения (добавлено docs-writer 19.09.2026)
| **Ситуация** | **Текст** | **Где** |
|:--|:--|:--|
| Поиск или фильтрация не дали результата | «Ничего не найдено» | Combobox, Multiselect с поиском |
| Источник пуст, поиска не было | Контекстный текст, например «Нет доступных проектов» | Все потребители |
| Запрос короче минимальной длины | Подсказка, например «Введите не меньше 2 символов» | Combobox с асинхронным поиском |
| Ошибка загрузки | «Не удалось загрузить» + действие «Повторить» | Все потребители с асинхронной загрузкой |

- Empty-сообщение не является option: его не выбрать и на нём нет Active;
- Изменение результата (появился Empty, найдено N вариантов) объявляется через live region (WCAG 2.2, 4.1.3 Status Messages);
- Если в Combobox разрешено создание, вместо Empty показывается один пункт «Создать «…»» — см. «Создать …» ниже.

## Loading
Когда варианты загружаются асинхронно:
- Показывайте Spinner внутри Dropdown;
- Сохраняйте размеры контейнера стабильными;
- Не показывайте старые варианты как актуальные, если они больше невалидны;
- После загрузки заменяйте Loading списком или Empty.

### Loading: уточнения (добавлено docs-writer 19.09.2026)
- Рядом со Spinner показывается текст «Загрузка…»: он же объявляется screen reader через live region;
- Loading внутри Dropdown и Spinner в поле владельца — разные состояния. Первое загружает варианты, второе проверяет выбранное значение (см. `select.md`, «Асинхронная проверка»);
- При подгрузке следующей порции длинного списка Spinner показывается последним пунктом, уже загруженные варианты остаются доступными.

# Dropdown Item
- Dropdown Item представляет вариант выбора или служебный элемент списка.

## Типы
| **Тип** | **Назначение** | **Интерактивность** |
|:--|:--|:--|
| Value | Вариант, который можно выбрать | Да |
| Group Title | Название группы вариантов | Возможно |
| Divider | Визуально разделяет группы | Нет |
| Create (добавлено docs-writer 19.09.2026) | Создаёт новое значение из введённого текста, только Combobox и Multiselect с поиском | Да |
| Select All (добавлено docs-writer 19.09.2026) | Выбирает или снимает все доступные варианты, только Multiselect | Да |

Интерактивность Group Title («Возможно») решена пользователем 19.09.2026 (см. «Решения для согласования», п. 4): в single Group Title не выбирается и пропускается при навигации клавиатурой, как описано в `select.md`; в multi клик по нему выбирает всю группу. (добавлено docs-writer 19.09.2026)

Divider — это компонент Divider дизайн-системы (горизонтальный), без собственного оформления внутри Dropdown. (добавлено docs-writer 19.09.2026)

## Анатомия Value (добавлено docs-writer 19.09.2026)
| **Элемент** | **Назначение** | **Обязательность** |
|:--|:--|:--|
| Checkbox | Индикатор выбора в режиме multi | Только multi |
| Leading Icon | Иконка, аватар или цветовой маркер варианта | Опционально |
| Label | Название варианта | Обязательно |
| Description | Вторая строка с пояснением | Опционально |
| Check Indicator | Индикатор выбора в режиме single | Опционально, только single |

Порядок слева направо: **Checkbox → Leading Icon → Label / Description → Check Indicator**.

## Leading Zone
- Dropdown Item может содержать Leading Icon.
- Используйте ее, когда иконка помогает различать варианты: тип файла, сущность, категорию и т. п. В одной группе сохраняйте единый принцип использования иконок.

### Leading Zone: уточнения (добавлено docs-writer 19.09.2026)
- Вместо иконки можно использовать Avatar (люди, команды) или цветовой маркер (статусы, категории). Размер определяется размером пункта;
- Если хотя бы у одного пункта группы есть Leading Icon, у пунктов без иконки место под неё сохраняется, чтобы тексты стояли на одной линии;
- Leading Icon не заменяет текст: Label обязателен всегда.

## Description (добавлено docs-writer 19.09.2026)
Вторая строка под Label поясняет вариант: email под именем пользователя, путь под названием проекта, краткое описание тарифа.
- Используйте Description, когда без неё варианты с похожими названиями трудно различить;
- Description — до 2 строк, затем многоточие и Tooltip;
- Текст Description вторичен: меньший кегль или приглушённый цвет, но контраст не ниже 4,5 : 1 (WCAG 2.2, 1.4.3);
- Description входит в доступное описание option (например, через `aria-describedby`), чтобы screen reader читал её вместе с Label;
- В одной группе либо у всех пунктов есть Description, либо ни у кого.

## Выбранное значение
Текущий выбранный Dropdown Item может иметь Check Indicator.
- Иконка Check — опциональна;
- Если используется, применяйте его последовательно для всех выбранных состояний;
- Индикатор дублирует выбор визуально, но не заменяет семантику selected;
- В single-select одновременно выбрано только одно значение.

### Single и Multi (добавлено docs-writer 19.09.2026)
| **Режим** | **Индикатор** | **Позиция** | **После выбора** | **Потребители** |
|:--|:--|:--|:--|:--|
| single | Check Indicator (опционально) + фон Selected | В конце пункта | Dropdown закрывается | Select, Combobox |
| multi | Checkbox (обязательно) | В начале пункта | Dropdown остаётся открытым | Multiselect |

- В режиме multi используется компонент Checkbox дизайн-системы. Его состояния (не отмечен · отмечен · indeterminate) повторяют выбор пункта. Сам Checkbox не получает фокус и скрыт от screen reader: семантику выбора несёт option через `aria-selected`;
- Indeterminate показывается только у Select All и у Group Title, если выбрана часть группы;
- Check Indicator и Checkbox в одном списке не смешиваются.

## Состояния Dropdown Item
| **Состояние** | **Описание** |
|:--|:--|
| Default | Доступный вариант без наведения |
| Hover | Указатель мыши находится над пунктом |
| Pressed | Момент выбора мышью |
| Active / Keyboard Focus | Текущий пункт при навигации клавиатурой |
| Read Only | Вариант видим, но недоступен для выбора |

- Read Only Item используйте только если пользователю важно видеть недоступный вариант. В реализации передавайте его как недоступную option.

### Selected — отдельное свойство (добавлено docs-writer 19.09.2026)
Selected не входит в таблицу состояний: это отдельное свойство, которое сочетается с любым состоянием. Выбранный пункт бывает Hover, Active или Read Only.
| **Комбинация** | **Как выглядит** |
|:--|:--|
| Selected + Default | Фон Selected, Check Indicator или отмеченный Checkbox |
| Selected + Hover / Pressed | Фон Selected с наложением Hover / Pressed |
| Selected + Active | Фон Selected и индикатор клавиатурного фокуса |
| Selected + Read Only | Выбор виден, но изменить его нельзя (например, обязательный участник) |

- Active показывается при навигации клавиатурой, Hover — при наведении мышью. Если указатель стоит над одним пунктом, а клавиатура на другом, Active один — последний, на который пришло действие;
- Selected нельзя передавать только цветом: в single нужен Check Indicator или отличие фона не ниже 3 : 1 (WCAG 2.2, 1.4.11), в multi это обеспечивает Checkbox.

## Длинный текст
- Value по возможности показывается полностью;
- Для длинного Group Title допускается до 4 строк;
- После ограничения текст сокращается многоточием;
- При наведении показывайте Tooltip с полным текстом.

Не делайте высоту всех пунктов фиксированной, если это приводит к систематическому обрезанию названий.

Tooltip с полным текстом открывается и при Active (клавиатура), не только при наведении (WCAG 2.2, 1.4.13). (добавлено docs-writer 19.09.2026)
## Группировка и порядок
- Располагайте варианты в одном столбце;
- Используйте понятную сортировку: алфавит, номер, частота, этап процесса;
- Связанные варианты можно объединять через Group Title;
- Divider используйте только для смыслового разделения;
- Если есть отдельное значение сброса — «Все», «Любой», «Неважно» — его можно отделить Divider.

### Группы: уточнения (добавлено docs-writer 19.09.2026)
- Группа с Group Title в разметке — `role="group"` с `aria-labelledby` на Group Title;
- Если после фильтрации в группе не осталось вариантов, скрывается и её Group Title, и соседний лишний Divider;
- Divider не ставится первым или последним элементом списка и не ставится дважды подряд.

## Подсветка совпадения (добавлено docs-writer 19.09.2026)
Используется в Combobox и в Multiselect с поиском: часть Label, совпавшая с запросом, выделяется.
- Выделение — начертанием (полужирный), а не только цветом (WCAG 2.2, 1.4.1);
- Подсвечиваются все вхождения запроса в Label, в Description — нет;
- Сравнение не зависит от регистра, «е» и «ё» считаются одной буквой;
- Подсветка — визуальная: screen reader читает Label целиком, без разбивки на части.

## «Создать …» (добавлено docs-writer 19.09.2026)
Пункт Create доступен только в Combobox и в Multiselect с поиском, когда создание нового значения разрешено.
- Текст: «Создать «{запрос}»». Запрос показывается как есть, без изменения регистра;
- Показывается, если введённый текст не совпадает полностью ни с одним вариантом (с учётом правил сравнения выше);
- Располагается последним и закреплён внизу Dropdown, перед ним — Divider;
- Leading Icon «+» обязателен: она отличает действие от варианта;
- Если других вариантов нет, пункт Create заменяет Empty. Это следует правилу «не показывать одновременно Empty и Dropdown Item»;
- После создания новое значение становится выбранным, пункт Create исчезает.

## Regular и Inverse (добавлено docs-writer 19.09.2026)
Dropdown повторяет режим владельца: Regular на светлых поверхностях, Inverse на тёмных. Inverse — это режим dark на фрейме, отдельных inverse-вариантов у Dropdown нет.

## Управление клавиатурой (добавлено docs-writer 19.09.2026)
Фокус остаётся на контроле-владельце, Dropdown Item не получает отдельной Tab-остановки. Общие правила для всех потребителей:
| **Действие** | **Результат** |
|:--|:--|
| ↑ / ↓ | Перемещает Active по доступным вариантам |
| Home / End | Первый / последний вариант (в Combobox — каретка в поле, см. `combobox.md`) |
| Enter | Выбирает Active Item; в single закрывает Dropdown |
| Space | В single выбирает и закрывает; в multi переключает Active Item. В Combobox вводит пробел |
| Escape | Закрывает Dropdown без изменения значения |
| Tab | Закрывает Dropdown и переводит фокус дальше |

Read Only, Group Title и Divider пропускаются при навигации. Когда Active доходит до края списка, ↑ / ↓ дальше не перемещают (без перехода по кругу).

## Доступность (A11y) (добавлено docs-writer 19.09.2026)
- Dropdown — `role="listbox"`, связанный с владельцем через `aria-controls`; в multi — с `aria-multiselectable="true"`;
- Value и Create — `role="option"`, у Value — `aria-selected`;
- Active передаётся через `aria-activedescendant` на владельце;
- Read Only — `aria-disabled="true"`;
- Group Title — подпись `role="group"`, не option;
- Divider, Check Indicator, Checkbox в пункте, декоративная Leading Icon — `aria-hidden="true"`;
- Empty и Loading объявляются через live region;
- Активная область пункта — вся строка, не только текст. Высота строки не меньше 24 px (WCAG 2.2, 2.5.8 Target Size).

## Делать (добавлено docs-writer 19.09.2026)
- Держать размер Dropdown равным размеру владельца;
- Различать Selected и Active и в оформлении, и в семантике;
- Показывать Empty и Loading текстом, а не пустым контейнером;
- Использовать Checkbox только в режиме multi, Check Indicator — только в single.

## Не делать (добавлено docs-writer 19.09.2026)
- Не показывать Empty вместе с вариантами;
- Не выделять совпадение только цветом;
- Не давать пунктам отдельную Tab-остановку;
- Не использовать Dropdown как контейнер для произвольного контента: формы, таблицы, календарь — это Popover.

## Связанные компоненты (добавлено docs-writer 19.09.2026)
| **Компонент** | **Когда использовать** |
|:--|:--|
| Select | Выбор одного значения из известного списка |
| Combobox | Выбор с поиском и фильтрацией |
| Multiselect | Выбор нескольких значений |
| Menu | Список действий, а не значений |
| Checkbox | Индикатор выбора в режиме multi |
| Divider | Разделение групп |
| Popover | Произвольный контент поверх интерфейса |

# Решения для согласования (добавлено docs-writer 19.09.2026)
1. **`_Dropdown Item` не публикуется, в том числе для Menu.** У пункта меню другая семантика (`menuitem`, подменю, горячие клавиши, нет Selected). Предлагаем: Menu публикует свой `Menu Item`, собранный на приватном `_Dropdown Item`. Так общая геометрия и состояния сохраняются, а дизайнер не вставит пункт выбора в меню действий. Альтернатива — опубликовать `Dropdown Item` для кастомных списков; тогда ему нужна отдельная документация.
2. **Позиция индикатора.** Check Indicator (single) стоит в конце пункта, Checkbox (multi) — в начале. Так Leading Icon в single остаются на одной линии, а в multi Checkbox стоит там, где его ищут глазами (как в Primer ActionList). В `select.md` позиция Check не задана.
3. **Selected — свойство, а не состояние.** В таблице состояний из `select.md` Selected нет. Предлагаем свойство Selected (да · нет), сочетаемое со всеми состояниями: в `_Dropdown Item` это отдельное свойство варианта.
4. **Group Title «Возможно» интерактивен.** Предлагаем: в single не интерактивен никогда; в multi — опционально, как «выбрать всю группу», с Checkbox и indeterminate. Тогда в multi он получает Tab-навигацию как option, и правило «Group Title пропускается» в `select.md` для multi не действует. ~~Нужно подтверждение.~~ **Принято пользователем 19.09.2026:** в Select (single) Group Title не интерактивен; в Multiselect клик по Group Title выбирает всю группу.
5. **Максимальная высота = 10 пунктов Value.** «До 10 вариантов без Scroll» трактуется как высота контейнера. Вопрос: обрезать ли последний видимый пункт наполовину как подсказку о прокрутке (тогда полностью видно 9,5)?
6. **Тексты Empty и Loading.** «Ничего не найдено» — только для пустого результата поиска; для пустого источника — контекстный текст; «Загрузка…» рядом со Spinner. Ошибка загрузки — отдельное Empty с «Повторить».
7. **«Создать …» последним и закреплён**, при отсутствии совпадений заменяет Empty.
8. **Подсветка совпадения — полужирным**, без учёта регистра, «е» = «ё».
9. **Без перехода по кругу** для ↑ / ↓ (как в примерах APG для listbox). Вариант с кругом — если команда предпочитает.
10. **Минимальная высота пункта 24 px** — нижняя граница из WCAG 2.5.8; фактические высоты S / M / L определяет ds-architect на уровне 2.
