# Multiselect
Multiselect — поле для выбора нескольких значений из заранее известного или загружаемого набора. Пользователь отмечает варианты в Dropdown, выбранные значения показываются в поле как Chips или сводкой «Выбрано: N».

Компонент состоит из трех частей:
| **Часть** | **Назначение** |
|:--|:--|
| Поле Multiselect | Показывает выбранные значения, открывает / закрывает список; при поиске принимает ввод |
| Dropdown | Список вариантов в режиме multi — см. `dropdown.md` |
| Chip | Выбранное значение в поле, которое можно удалить |

💡
Label, Description и текст валидации относятся к обертке поля — Field.

## Использовать
- Можно выбрать несколько значений из списка: исполнители, теги, регионы, статусы в фильтре;
- Список не помещается в группу Checkbox на странице или меняется в зависимости от данных;
- Нужно видеть и редактировать выбор, не открывая список.

## Не использовать
| **Задача** | **Компонент** |
|:--|:--|
| Можно выбрать только одно значение | Select / Combobox |
| До 5–7 вариантов, которые полезно видеть сразу | Группа Checkbox |
| Быстрые фильтры над таблицей или каталогом, всё видно сразу | Группа Chip в режиме toggle |
| Нужно ввести произвольные значения без списка (email, теги) | Token Input (план) |

## Размеры
Multiselect, Dropdown и Dropdown Item поддерживают размеры S / M / L.
| **Размер** | **Где применять** |
|:--|:--|
| S | Таблицы, фильтры, плотные панели — обычно со сводкой «Выбрано: N» |
| M | Стандартный размер для большинства форм |
| L | Крупные формы и сценарии с повышенным визуальным приоритетом |

Chip внутри поля берётся из компонента Chip; соответствие размеров — в «Решениях для согласования».

## Отличия от оболочки Input
Поле Multiselect наследует оболочку Input (`input.md`, раздел «Оболочка поля (база семейства)»): контейнер, состояния, Placeholder, Leading Zone, Clear, State Icon, Spinner. Ниже — только отличия.
| **Что** | **Input** | **Multiselect** |
|:--|:--|:--|
| Content | Одно Value | Chips с «+N» или сводка «Выбрано: N» |
| Chevron | Нет | Есть, последним в Trailing Zone |
| Open | Нет | Признак раскрытия Dropdown, существует параллельно с Focused |
| Clear | Очищает текст | Снимает весь выбор («Очистить всё») |
| Ввод | Свободный | Только как поиск по списку, если поиск включён |
| Suffix, Actions | Да | Нет, кроме Clear |

Состояния поля — как у оболочки Input: Default, Hover, Focused, Disabled, Read Only, Error, Warning, Success, Loading, плюс признак Open.

## Отображение выбора в поле
| **Вид** | **Как выглядит** | **Когда применять** |
|:--|:--|:--|
| Chips | Каждое значение — Chip с «×». Что не поместилось в одну строку — Chip «+N» | Формы, где важно видеть, что именно выбрано |
| Сводка | Текст «Выбрано: N»; при выборе всех — «Все» | Фильтры, таблицы, размер S, длинные списки |

### Chips
- Используется Chip дизайн-системы в режиме **Removable**, стиль Soft, тон Neutral (`chip.md`, «Минимальная палитра» — сценарий «Мультиселект / выпадающий выбор»);
- Форма Chip — по смыслу значения (`chip.md`, «Форма»): Circle — люди, теги, категории; Square — статусы, объекты, технические значения;
- Chips идут в порядке выбора: новое значение добавляется в конец;
- Поле остаётся однострочным. Chips, которые не поместились, заменяются одним Chip «+N». «+N» не удаляется, клик по нему открывает Dropdown, Tooltip показывает скрытые значения;
- Длинное значение в Chip сокращается многоточием, полный текст — в Tooltip (`chip.md`, «Ограничения»);
- Поле поиска, если оно есть, стоит после последнего Chip и занимает оставшееся место;
- В Disabled и Read Only у Chips нет «×».

### Сводка
- Формат: «Выбрано: N». Если выбраны все варианты — «Все»;
- При одном выбранном значении показывается само значение, а не «Выбрано: 1»;
- Сводка не заменяет доступное имя: screen reader читает Label поля и число выбранных.

## Dropdown в режиме multi
Список строится на `dropdown.md` в режиме multi. Специфика Multiselect:
- Индикатор выбора — Checkbox в начале пункта;
- После выбора Dropdown **не закрывается**: пользователь отмечает несколько вариантов подряд;
- Пока Dropdown открыт, порядок пунктов не меняется. Отмеченные варианты не прыгают наверх;
- При повторном открытии порядок исходный. Для длинных списков можно показать группу «Выбранные» над остальными — см. «Решения для согласования»;
- Dropdown закрывается по Escape, Tab, клику вне или по Chevron.

### Выбрать все
- Пункт Select All («Выбрать все») стоит первым и закреплён сверху, перед ним ничего нет, после — Divider;
- Checkbox пункта: не отмечен — ничего не выбрано; отмечен — выбраны все; indeterminate — выбрана часть;
- При активном поиске действует только на найденные варианты, текст меняется на «Выбрать найденные»;
- Недоступные (Read Only) варианты не затрагиваются;
- Не показывается, если установлен лимит выбора меньше числа вариантов.

### Очистить всё
- Clear (×) в Trailing Zone снимает весь выбор без подтверждения;
- Показывается, когда выбрано хотя бы одно значение, не показывается в Disabled и Read Only;
- После очистки фокус остаётся в поле.

## Поиск внутри
| **Вид поля** | **Где поиск** |
|:--|:--|
| Chips | В самом поле, после Chips — как в Combobox |
| Сводка | Поле поиска вверху Dropdown, закреплено при прокрутке |

- Фильтрация, подсветка совпадения, Empty и асинхронная загрузка — как в `combobox.md`;
- Выбор варианта не очищает запрос: можно отметить несколько найденных подряд;
- Если разрешено создание, работает пункт «Создать «{запрос}»» (`dropdown.md`).

## Лимит выбора
- Лимит задаётся сценарием, по умолчанию его нет;
- Лимит сообщается заранее в Description Field: «Можно выбрать до N»;
- Когда лимит достигнут, невыбранные варианты становятся Read Only, выбранные можно снять;
- Попытка выбрать сверх лимита не показывает Error: варианты уже недоступны, а Description объясняет причину.

## Валидация
- Основная ошибка — не выбрано обязательное минимальное число значений. Error показывается после попытки отправить форму или ухода из поля;
- Отдельный Chip может быть в Error (тон Danger — `chip.md`, сценарий Token input), если значение стало недоступным после выбора;
- Error всегда сопровождается текстом в Validation Message Field.

## Управление клавиатурой
Фокус остаётся в поле. Active Item передаётся через `aria-activedescendant`.
| **Действие** | **Результат** |
|:--|:--|
| Tab | Переводит фокус в поле и далее. Открытый Dropdown закрывается, выбор сохраняется |
| Enter / ↓ / Alt + ↓ | Открывает Dropdown |
| ↑ / ↓ | Перемещают Active по вариантам |
| Home / End | Первый / последний вариант (в поле с поиском — каретка в тексте) |
| Space | Отмечает / снимает Active Item (в поле с поиском — только Enter, Space вводит пробел) |
| Enter при открытом Dropdown | Отмечает / снимает Active Item, Dropdown не закрывается |
| Ctrl / Cmd + A при открытом Dropdown | Выбирает все доступные варианты (без поиска) |
| Escape | Закрывает Dropdown, выбор сохраняется |
| Backspace при пустом запросе | Удаляет последний Chip |
| ← при пустом запросе | Переводит фокус на последний Chip; дальше ← / → перемещают фокус между Chips |
| Backspace / Delete на Chip | Удаляет Chip, фокус переходит на соседний Chip или в поле |

## Regular и Inverse
| **Режим** | **Где применять** |
|:--|:--|
| Regular | Светлые и стандартные поверхности |
| Inverse | Темные поверхности |

Inverse — режим dark на фрейме; Chips и Dropdown повторяют режим поля.

## Доступность (A11y)
- Поле — `role="combobox"` с `aria-expanded` и `aria-controls`; с поиском — ещё `aria-autocomplete="list"`;
- Dropdown — `role="listbox"` с `aria-multiselectable="true"`, варианты — `role="option"` с `aria-selected`;
- Checkbox внутри пункта декоративный (`aria-hidden="true"`): состояние выбора передаёт `aria-selected`;
- Select All — option с состоянием `aria-checked="mixed"` для частичного выбора или отдельная кнопка над списком — решается в реализации, но состояние должно объявляться;
- Chips — `role="group"` с доступным именем, например «Выбранные значения»; «×» — кнопка с `aria-label="Удалить {значение}"` (`chip.md`);
- Добавление и удаление значения объявляются через live region: «{значение} добавлено», «Выбрано: N»;
- Chip «+N» имеет доступное имя «Ещё N выбранных» и открывает Dropdown;
- Error — `aria-invalid="true"` и связанное сообщение;
- Focus Ring виден на поле и на каждом Chip при клавиатурной навигации.

## Адаптив
- На узком экране поле занимает доступную ширину, Chips перестраиваются, «+N» появляется раньше;
- Dropdown может перестраиваться в широкую мобильную панель с кнопкой «Готово»;
- Не уменьшайте Chips и активные области ради desktop-вида.

## Делать
- Держать Dropdown открытым при множественном выборе;
- Показывать выбор в поле Chips или сводкой;
- Сообщать лимит до того, как пользователь в него упрётся;
- Использовать Chip дизайн-системы, а не собственные метки.

## Не делать
- Не использовать Multiselect для одного значения;
- Не переставлять пункты списка, пока он открыт;
- Не смешивать Chips и сводку в одном поле;
- Не делать поле многострочным без ограничения высоты.

## Связанные компоненты
| **Компонент** | **Когда использовать** |
|:--|:--|
| Field | Label, Description (лимит), Required и Validation Message |
| Select | Одно значение из известного списка |
| Combobox | Одно значение с поиском |
| Checkbox | Индикатор выбора в пункте; группа Checkbox для короткого видимого списка |
| Chip | Выбранное значение в поле (`chip.md`, `src/components/chip.json`) |
| Dropdown / Dropdown Item | Список вариантов (`dropdown.md`) |

# Решения для согласования
1. **Chip внутри поля — наш Chip** (`src/components/chip.json`): режим Removable, стиль Soft, тон Neutral, форма по смыслу значения. У Chip только два размера: S и M. Предлагаем Chip S в поле S и M, Chip M в поле L. Высоту Chip и внутренний отступ поля нужно сверить на уровне 2 (ds-architect): Chip должен помещаться в высоту поля без увеличения её.
2. **Поле однострочное, лишнее уходит в «+N».** Многострочный вариант с ростом высоты не вводим: он сдвигает форму при каждом выборе. Если нужен, то с ограничением высоты и прокруткой внутри поля — отдельным решением.
3. **Chips — в порядке выбора, список — в исходном порядке и не меняется, пока открыт.** Carbon по умолчанию поднимает выбранные наверх при повторном открытии (`selectionFeedback="top-after-reopen"`). Предлагаем не переставлять, а для длинных списков (больше 10 пунктов, где начинается Scroll) опционально показывать группу «Выбранные» сверху. Нужно решение.
4. **Сводка: «Выбрано: N», при всех — «Все», при одном — само значение.**
5. **Поиск: в поле — для вида Chips, в Dropdown — для вида Сводка.** Так поле со сводкой остаётся кнопкой, как Select Button (похоже на Primer SelectPanel).
6. **«Выбрать все» — первым пунктом с indeterminate;** при поиске — «Выбрать найденные»; скрыт при лимите.
7. **Лимит: невыбранные варианты — Read Only, без Error**, лимит заранее в Description.
8. **Checkbox в пункте скрыт от screen reader** (`aria-hidden`), выбор передаёт `aria-selected` у option. Так в option нет вложенного интерактивного элемента.
9. **Навигация по Chips стрелкой ← из пустого поля, удаление Backspace** — поведение, которое пользователь просил для Backspace, расширено до перемещения по Chips.
10. **Clear снимает весь выбор без подтверждения** — как удаление Chip «×» в `chip.md`.
11. **Group Title выбирает всю группу; Chevron последний в правой зоне.** **Принято пользователем 19.09.2026:** в Multiselect клик по Group Title выбирает всю группу (Checkbox с indeterminate, см. `dropdown.md`, решение 4); Chevron — после Clear и State Icon / Spinner (`select.md`, решение 2).
