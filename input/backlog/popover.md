# Popover
Popover — всплывающая панель, которая открывается по клику на триггер и содержит произвольный контент: текст, ссылки, поля, до двух действий. Popover привязан к триггеру, не блокирует страницу и закрывается по Escape, по клику вне и по своей кнопке закрытия.

Документа пользователя по Popover нет: текст написан по WAI-ARIA APG (`dialog`, non-modal), WCAG 2.2 (1.4.13, 2.4.3 Focus Order, 2.1.2 No Keyboard Trap) и практике Material 3, Carbon, Atlassian, Polaris, Primer. Свои числа и решения собраны в разделе «Решения для согласования». (docs-writer 20.09.2026)

| **Часть** | **Назначение** |
|:--|:--|
| Popover | Панель с контентом поверх интерфейса |
| Триггер | Кнопка или другой интерактивный элемент, который открывает и закрывает панель |

💡
Popover не существует сам по себе: он всегда привязан к триггеру и к его положению на экране. Если содержимое не связано с конкретной точкой интерфейса, это Modal или отдельная страница.

## Пять компонентов сообщений: когда что
| **Задача** | **Компонент** |
|:--|:--|
| Короткое пояснение к элементу по наведению и фокусу, без интерактива | Tooltip |
| **Панель по клику: произвольный контент, ссылки, поля, до двух действий** | **Popover** |
| Сообщение обо всей странице или разделе, на всю ширину контейнера | Banner |
| Сообщение о конкретном блоке контента или форме, в потоке | Alert |
| Обучающая подсказка: система показывает, как работает функция; шаги тура | Hint |
| Короткое уведомление о результате действия, исчезает само | Toast |
| Задача, которая требует ответа и блокирует работу | Modal |
| Список команд по клику | Menu |
| Выбор значения из списка | Select, Combobox, Multiselect + Dropdown |

## Использовать
- Показать подробное пояснение со ссылкой на справку;
- Открыть второстепенные настройки, которые не нужны постоянно;
- Показать карточку сущности при клике на имя, аватар, код заказа;
- Собрать короткую форму из одного-двух полей: фильтр, переименование, комментарий;
- Показать подтверждение простого и не разрушительного действия рядом с кнопкой;
- Дать пояснение там, где Tooltip не работает: на тач-устройствах и при интерактивном содержимом.

## Не использовать
| **Задача** | **Компонент** |
|:--|:--|
| Короткая подсказка без интерактива, по наведению | Tooltip |
| Список команд, из которого выбирают одну | Menu |
| Выбор значения из набора вариантов | Select · Combobox · Multiselect (Dropdown) |
| Задача из нескольких шагов, длинная форма | Modal · Drawer · отдельная страница |
| Подтверждение удаления и других необратимых действий | Modal |
| Сообщение о состоянии страницы или формы | Banner · Alert |
| Сообщение о результате действия, которое можно не читать | Toast |
| Обучение работе с функцией, тур по интерфейсу | Hint |

### Popover и Modal
| **Что** | **Popover** | **Modal** |
|:--|:--|:--|
| Привязка | К триггеру, позиционируется рядом | К центру экрана |
| Затемнение | Нет | Есть (scrim) |
| Работа со страницей | Продолжается, страница не блокируется | Блокируется до ответа |
| Фокус | Не запирается, Tab уходит дальше по странице | Запирается внутри окна |
| Прокрутка страницы | Разрешена, popover следует за триггером или закрывается | Заблокирована |
| Содержимое | Короткое, один смысловой блок | Задача любой сложности |
| Необратимые действия | Нет | Да |

### Popover и Menu
| **Что** | **Popover** | **Menu** |
|:--|:--|:--|
| Содержимое | Произвольное: текст, поля, ссылки, кнопки | Список команд |
| Роль | *dialog* | *menu* / *menuitem* |
| Клавиатура | Обычный Tab по содержимому | Стрелки, одна Tab-остановка (roving tabindex) |
| Выбор | Пользователь работает с содержимым | Активация пункта закрывает меню |

## Состав
| **Элемент** | **Назначение** | **Обязателен** |
|:--|:--|:--|
| Контейнер | Поверхность панели: фон, обводка, скругление, тень | Да |
| Заголовок | Название панели, 1 строка | Нет, но рекомендуется |
| Кнопка закрытия | Закрывает панель, возвращает фокус на триггер | Нет |
| Контент | Текст, список, поля, изображение | Да |
| Действия (Footer) | До двух кнопок: основное и отменяющее | Нет |
| Хвостик (Tail) | Указывает на триггер | Нет |

Заголовок и кнопка закрытия появляются парой: если есть заголовок, кнопка закрытия стоит в той же строке справа.

## Размеры
У Popover нет оси размера контрола: размер задаётся шириной панели, высота — по содержимому.

| **Ширина** | **Значение** | **Токен уровня 2** | **Где применять** |
|:--|:--|:--|:--|
| S | 240 | `size/overlay/width-compact` | Одно пояснение, одно поле, компактная панель у кнопки в тулбаре |
| M | 320 | `size/overlay/width` | Стандарт: текст со ссылкой, карточка сущности, короткая форма |
| L | 400 | `size/overlay/width-wide` | Настройки фильтра, форма из двух полей, список свойств |

| **Свойство** | **Значение** | **Токен уровня 2** |
|:--|:--|:--|
| Внутренний отступ панели-обёртки | 8 | `space/overlay/popover-padding` |
| Внутренний отступ панели с заголовком и действиями | 16 (решение, токена нет) | см. «Решения для согласования» |
| Скругление | 8 | `radius/popover` |
| Тень | 0 · 8 · 16 · −2 | `shadow/popover/*` |
| Слой | 1500 — выше модалки, ниже toast и tooltip | `z-index/popover` |
| Зазор до триггера (до острия хвостика) | 4 | `space/overlay/offset` |
| Хвостик: основание и вылет | 8 · 4 | `size/overlay/arrow`, `size/overlay/arrow-depth` |
| Заголовок | 16 / 24, 600 | `typography/heading/subsection` |
| Текст | 14 / 20, 400 | `typography/body/ui` |
| Вертикальный ритм блоков | 8 | `space/stack/default` |

Максимальная высота ограничена видимой областью: содержимое сверх неё прокручивается внутри панели, заголовок и действия остаются на месте.

## Содержимое
- Один смысловой блок: одна тема, один вопрос, одна группа настроек;
- Заголовок — до 1 строки, без точки;
- Текст — до 4–5 строк; если длиннее, это Modal или страница справки;
- Действий не больше двух: основное и отменяющее;
- Ссылка «Подробнее» ведёт на полную справку и закрывает popover при переходе;
- Поля внутри popover оборачиваются в Field и работают по обычным правилам формы;
- Внутри popover не открывают второй popover; допустимы Select, Combobox и их Dropdown — они рисуются выше по слою.

## Состояния
Сама панель не имеет состояний наведения и нажатия: они принадлежат её содержимому и триггеру.

| **Состояние** | **Когда** | **Поведение** |
|:--|:--|:--|
| Closed | Панель не открыта | В DOM её нет или она скрыта, триггер `aria-expanded="false"` |
| Open | Триггер нажат | Панель видна, позиция рассчитана, фокус переведён внутрь |
| Loading | Содержимое загружается | В панели Spinner или Skeleton, размер не скачет |
| Empty | Данных нет | Короткое пояснение вместо содержимого |

**Триггер.** Пока панель открыта, триггер остаётся в состоянии Pressed или Selected: пользователь видит, откуда открыта панель.

## Варианты и роли
- **Ролей (info · success · warning · danger) у Popover нет.** Панель нейтральна: `color/layer/popover/neutral/default`. Сообщение со статусом внутри панели — это Alert.
- **Вариант «с заголовком» и «без заголовка»** — свойство, а не роль.
- **Позиция** — сторона (top · bottom · left · right) и выравнивание (start · center · end), 12 комбинаций, как у Tooltip.
- **Инверсный вид** — режим dark на фрейме, отдельных токенов нет.

## Поведение
| **Событие** | **Что происходит** |
|:--|:--|
| Клик по триггеру | Панель открывается, фокус переходит внутрь |
| Повторный клик по триггеру | Панель закрывается, фокус остаётся на триггере |
| Escape | Панель закрывается, фокус возвращается на триггер |
| Клик вне панели и вне триггера | Панель закрывается; фокус на триггер не возвращается — он уходит туда, куда кликнул пользователь |
| Tab с последнего элемента панели | Панель закрывается, фокус продолжает обычный порядок страницы |
| Основное действие в футере | Выполняется, панель закрывается, фокус возвращается на триггер |
| Отмена в футере | Изменения не применяются, панель закрывается, фокус возвращается на триггер |
| Прокрутка страницы | Панель следует за триггером; когда триггер ушёл из видимой области, панель закрывается |
| Изменение размера окна | Позиция пересчитывается, при нехватке места — переворот и сдвиг |
| Наведение курсора | Ничего не происходит: popover не открывается по наведению |

Popover не открывается автоматически при загрузке страницы, кроме онбординга, который пользователь может закрыть.

### Позиционирование
- Предпочтительная сторона, автоматический переворот при нехватке места, сдвиг вдоль стороны;
- Зазор до триггера — 4, он меряется до острия хвостика;
- Панель не перекрывает свой триггер;
- Хвостик (основание 8, вылет 4) указывает на центр триггера; если после сдвига он подходит к углу ближе, чем на длину основания, хвостик скрывается;
- На узком экране панель шириной L разворачивается в нижнюю панель на всю ширину.

### Несохранённые данные
Если внутри есть поля, клик вне и Escape не должны молча терять введённое:
- Либо изменения применяются сразу (панель — набор настроек);
- Либо в футере есть явные «Применить» и «Отмена», и тогда клик вне закрытие подтверждает или отменяет по правилу продукта — правило должно быть одно на весь продукт;
- Длинная форма, которую жалко потерять, в popover не помещается: используйте Modal.

## Regular и Inverse
| **Режим** | **Где применять** |
|:--|:--|
| Regular | Светлые и стандартные поверхности |
| Inverse | Тёмные поверхности: панель наследует режим фрейма, отдельного варианта нет |

Все элементы внутри панели — Field, Button, Link — используют один режим с панелью.

## Доступность (A11y)
- Контейнер получает *role="dialog"* и *aria-modal="false"* (значение по умолчанию): страница остаётся доступной;
- Панель обязана иметь доступное имя: *aria-labelledby* на заголовок или *aria-label*, если заголовка нет;
- Триггер получает *aria-expanded* и *aria-haspopup="dialog"*, а также *aria-controls* с `id` панели;
- При открытии фокус переводится в панель: на первый интерактивный элемент, а если его нет — на контейнер с `tabindex="-1"`;
- Escape закрывает панель и **возвращает фокус на триггер** — это главное правило возврата фокуса;
- Фокус не запирается (WCAG 2.1.2): Tab с последнего элемента закрывает панель и продолжает порядок страницы. Если фокус нужно запереть, задача по сложности — Modal;
- Порядок Tab совпадает с визуальным: панель размещается в DOM сразу после триггера (WCAG 2.4.3);
- Панель не открывается по наведению: WCAG 1.4.13 применяется к содержимому, которое появляется по hover, popover этого сценария избегает;
- Кнопка закрытия получает доступное имя «Закрыть» и размер зоны нажатия не меньше 24 × 24 (WCAG 2.5.8);
- Содержимое панели не помещают в live-region: пользователь открыл её сам;
- Контраст текста ≥ 4,5 : 1, обводки и иконок ≥ 3 : 1 (WCAG 1.4.3, 1.4.11).

## Управление клавиатурой
| **Действие** | **Результат** |
|:--|:--|
| Enter / Space на триггере | Открывает панель, переводит фокус внутрь |
| Tab / Shift + Tab внутри панели | Перемещает фокус по интерактивным элементам панели |
| Tab с последнего элемента | Закрывает панель, фокус идёт дальше по странице |
| Shift + Tab с первого элемента | Возвращает фокус на триггер и закрывает панель |
| Escape | Закрывает панель, фокус возвращается на триггер |
| Enter в поле внутри панели | Выполняет основное действие, если оно есть |
| Escape при открытом Dropdown внутри панели | Сначала закрывается Dropdown, панель остаётся открытой |

## Делать
- Открывать popover только по клику;
- Возвращать фокус на триггер при Escape и при действиях футера;
- Оставлять в панели один смысловой блок и не больше двух действий;
- Показывать состояние триггера, пока панель открыта;
- Закрывать панель, когда триггер уходит из видимой области.

## Не делать
- Не открывать popover по наведению;
- Не складывать popover в popover;
- Не помещать в popover длинную форму и необратимые действия;
- Не запирать фокус внутри панели;
- Не открывать панель автоматически без действия пользователя;
- Не заменять popover'ом Menu, Select и Dropdown;
- Не терять введённые данные при закрытии без предупреждения.

## Связанные компоненты
| **Компонент** | **Когда использовать** |
|:--|:--|
| Tooltip | Короткая подсказка по наведению, без интерактива |
| Modal | Задача блокирует работу или необратима |
| Drawer | Длинная форма или список сбоку экрана |
| Menu | Список команд |
| Dropdown | Список вариантов для Select, Combobox, Multiselect |
| Field, Input, Select | Содержимое панели с формой |
| Button | Триггер и действия в футере |
| Alert | Сообщение со статусом внутри панели |
| Hint | Обучающая подсказка: онбординг, тур по интерфейсу |

# Решения для согласования (docs-writer 20.09.2026)
1. **С Popover снят флаг `hidden: true` в `src/catalog/components.json`.** Флаг поставили 19.09.2026, когда в плагине показывали только простые компоненты (`docs/decisions.md`). Теперь у компонента есть документ, а на уровне 2 уже готовы `color/layer/popover/*`, `radius/popover`, `shadow/popover/*`, `z-index/popover`, `space/overlay/popover-padding` — компонент можно описывать и собирать. То же сделано для Banner.
2. **Ширины S 240 · M 320 · L 400 — закрыто.** ds-architect 20.09.2026 завёл `size/overlay/{width-compact,width,width-wide}`. Это не ось размера контрола: типографика и высоты внутри панели от ширины не зависят.
3. **Отступ панели с заголовком и действиями — 16.** Существующий `space/overlay/popover-padding` = 8 описан как «popover с произвольным контентом, панель date-picker»: он подходит панели-обёртке, у которой содержимое несёт свои отступы (как `dropdown-padding`). Для панели с заголовком и футером предлагается `space/overlay/popover-content-padding` = 16. Решение — за ds-architect.
4. **Фокус внутри панели не запирается.** Popover — non-modal dialog: Tab с последнего элемента закрывает панель и продолжает порядок страницы. Альтернатива (запереть фокус, как в Modal) отклонена: она делает страницу недоступной без затемнения, и пользователь не понимает, почему фокус не уходит.
5. **Escape и действия футера возвращают фокус на триггер, клик вне — нет.** При клике вне пользователь сам указал, куда идти дальше.
6. **Кнопка закрытия опциональна, но обязательна, если внутри есть поля ввода**: на тач-устройствах Escape недоступен.
7. **Хвостик общий с Tooltip** — `size/overlay/arrow` = 8 и `size/overlay/arrow-depth` = 4 (ds-architect, 20.09.2026), цвет = цвет поверхности. Требует подтверждения поведение: хвостик опционален и скрывается, когда панель сильно сдвинута.
8. **В каталоге Popover остаётся `interactive: false`.** Это поверхность: состояния принадлежат триггеру и вложенным контролам, собственных `color/action/*` у панели нет.
9. **Роли (info · danger …) у панели нет.** Статусное сообщение внутри панели — экземпляр Alert.
