# Tooltip
Tooltip — короткая текстовая подсказка, которая появляется рядом с элементом при наведении курсора или при получении клавиатурного фокуса и исчезает, когда курсор и фокус уходят. Внутри тултипа только текст: ни ссылок, ни кнопок, ни полей.

Документа пользователя по Tooltip нет: текст написан по WAI-ARIA APG (`tooltip`), WCAG 2.2 (1.4.13 Content on Hover or Focus, 2.2.1 Timing Adjustable) и практике Material 3, Carbon, Atlassian, Polaris, Primer, GOV.UK. Свои числа и решения собраны в разделе «Решения для согласования». (docs-writer 20.09.2026)

| **Часть** | **Назначение** |
|:--|:--|
| Tooltip | Контейнер подсказки поверх интерфейса |
| Триггер | Элемент, к которому относится подсказка; сам тултип триггером не владеет |

💡
Тултип не хранит информацию, без которой нельзя выполнить задачу: он не виден на тач-устройствах, не виден при печати и исчезает, как только уходит курсор. Всё, что нужно всегда, показывается на странице — Description в Field или обычный текст рядом с элементом.

## Пять компонентов сообщений: когда что
| **Задача** | **Компонент** |
|:--|:--|
| **Короткое пояснение к элементу по наведению и фокусу, без интерактива** | **Tooltip** |
| Панель по клику: произвольный контент, ссылки, поля, до двух действий | Popover |
| Сообщение обо всей странице или разделе, на всю ширину контейнера | Banner |
| Сообщение о конкретном блоке контента или форме, в потоке | Alert |
| Обучающая подсказка: система показывает, как работает функция; шаги тура | Hint |
| Постоянная поясняющая строка под полем формы | Description в Field |
| Короткое уведомление о результате действия, исчезает само | Toast |
| Задача, которая требует ответа и блокирует работу | Modal |
| Список команд по клику | Menu |
| Ошибка конкретного поля | Validation Message в Field |

## Использовать
- Пояснить кнопку-иконку, у которой нет видимой подписи;
- Показать полный текст, обрезанный многоточием (`field.md`, `dropdown.md`, `status.md`, `chip.md`, `multiselect.md`);
- Раскрыть сокращение, единицу измерения, код статуса;
- Показать горячую клавишу действия;
- Показать точное значение у диаграммы, прогресса, относительной даты «3 дня назад».

## Не использовать
| **Задача** | **Компонент** |
|:--|:--|
| Внутри подсказки нужны ссылка, кнопка, поле или изображение | Popover |
| Пояснение должно быть видно всегда | Description в Field · текст рядом с элементом |
| Нужно обучить работе с функцией, провести по шагам | Hint |
| Сообщение об ошибке, предупреждение, успех | Alert / Banner / Validation Message |
| Текст длиннее двух строк, со списком или заголовком | Popover |
| Подтвердить действие, задать вопрос | Modal |
| Сообщить о результате асинхронной операции | Toast |
| Объяснить, что делать в пустом блоке | Empty State |

Тултип — дополнение к интерфейсу, а не его часть. Если пользователь без подсказки не справится, текст переносится на страницу.

## Состав
| **Элемент** | **Назначение** | **Обязателен** |
|:--|:--|:--|
| Контейнер | Поверхность подсказки: фон, скругление, тень | Да |
| Текст | Одна-две строки пояснения | Да |
| Хвостик (Tail) | Указывает на триггер | Нет |

У Tooltip **нет** заголовка, иконки, кнопки закрытия и действий. Как только эти элементы понадобились, это Popover.

## Размеры
У Tooltip нет оси размера: он один для триггеров всех размеров.

| **Свойство** | **Значение** | **Токен уровня 2** |
|:--|:--|:--|
| Текст | 12 / 16, 400 | `typography/body/small` |
| Отступ по горизонтали | 8 | `space/overlay/tooltip-padding-x` |
| Отступ по вертикали | 4 | `space/overlay/tooltip-padding-y` |
| Скругление | 6 | `radius/tooltip` |
| Тень | 0 · 2 · 8 · 0 | `shadow/tooltip/*` |
| Слой | 1700 — выше всех оверлеев | `z-index/tooltip` |
| Зазор до триггера (до острия хвостика) | 4 | `space/overlay/offset` |
| Максимальная ширина | 320 | `size/overlay/width` |
| Хвостик: основание и вылет | 8 · 4 | `size/overlay/arrow`, `size/overlay/arrow-depth` |

Ширина тултипа — по содержимому, но не больше максимума; дальше текст переносится. Тултип не растягивается на ширину триггера.

## Содержимое
- До 2 строк, ориентир — 120 знаков;
- Одна мысль: что это или что произойдёт;
- Без точки в конце, если это не полное предложение;
- Без списков, форматирования, ссылок и ручных переносов;
- Не повторяет видимую подпись рядом;
- У кнопки-иконки текст тултипа совпадает с её доступным именем: иначе пользователь клавиатуры и пользователь мыши получат разное;
- Полный текст обрезанного значения показывается без добавочных слов.

## Состояния
Сам Tooltip не интерактивен: у него нет Hover, Pressed, Disabled. Состояния описывают только видимость.

| **Состояние** | **Когда** | **Поведение** |
|:--|:--|:--|
| Hidden | Курсора и фокуса на триггере нет | Тултипа нет в потоке и нет для screen reader |
| Opening | Курсор на триггере, идёт задержка открытия | Пока ничего не показано |
| Visible | Задержка прошла или триггер получил фокус | Подсказка видна, позиция пересчитана |
| Closing | Курсор ушёл с триггера | Задержка закрытия: за это время курсор можно перевести на сам тултип |

**Триггер в Disabled.** У элемента с атрибутом `disabled` нет событий указателя и нет фокуса, поэтому подсказка «почему недоступно» не покажется. Если такое пояснение нужно, кнопка остаётся фокусируемой и помечается `aria-disabled="true"`, а не `disabled`.

## Варианты и роли
- **Ролей у Tooltip нет.** Он всегда нейтрален. Красный или жёлтый тултип не используется: статус несут Alert, Banner, State Icon поля и Status.
- **Вариант оформления один.** Инверсный (тёмный) тултип — не отдельный вариант, а тот же компонент во фрейме в режиме dark (`docs/architecture.md`: токенов `inverse-*` нет).
- **Позиция** — свойство, а не вариант: сторона (top · bottom · left · right) и выравнивание (start · center · end), 12 комбинаций.

## Поведение
| **Событие** | **Что происходит** |
|:--|:--|
| Наведение на триггер | Тултип появляется после задержки открытия |
| Клавиатурный фокус на триггере | Тултип появляется сразу, без задержки |
| Курсор ушёл с триггера | Тултип скрывается после задержки закрытия |
| Курсор переведён на сам тултип | Тултип остаётся открытым (WCAG 1.4.13, «можно навести») |
| Escape | Тултип закрывается, фокус остаётся на триггере (WCAG 1.4.13, «закрывается») |
| Фокус ушёл с триггера | Тултип закрывается |
| Клик или нажатие по триггеру | Тултип скрывается, выполняется действие триггера |
| Прокрутка, изменение размера окна | Позиция пересчитывается; когда триггер ушёл из видимой области, тултип закрывается |
| Наведение на другой триггер | Открытым остаётся один тултип |

Тултип не закрывается сам по таймеру: пользователь с медленным чтением должен успеть (WCAG 2.2.1).

### Позиционирование
- У триггера есть предпочтительная сторона; если места не хватает, тултип переворачивается на противоположную;
- Если не хватает вдоль стороны, тултип сдвигается, оставаясь в видимой области;
- Зазор до триггера — 4, он меряется до острия хвостика;
- Тултип не перекрывает свой триггер (WCAG 1.4.13, «не заслоняет»);
- Хвостик (основание 8, вылет 4) указывает на центр триггера и не подходит к углу контейнера ближе, чем на длину своего основания; если после сдвига он туда не помещается, хвостик скрывается, а тултип остаётся;
- Тултип не обрезается контейнером с прокруткой: он рисуется в слое `z-index/tooltip`.

### Тач-устройства
Наведения на тач нет, а долгое нажатие конфликтует с выделением текста и системными жестами.

| **Ситуация** | **Решение** |
|:--|:--|
| Обычный тултип на тач | Не показывается |
| Пояснение нужно и на тач | Триггер — кнопка-иконка «i», по тапу открывается Popover с тем же текстом |
| Обрезанный текст на тач | Показывается полностью по тапу (разворот строки или Popover) либо сокращается сам текст |
| Тултип у кнопки-иконки | Текст дублируется доступным именем, для screen reader этого достаточно |

Не вешайте тултип на долгое нажатие и не делайте его единственным способом узнать назначение элемента на мобильном.

## Regular и Inverse
| **Режим** | **Где применять** |
|:--|:--|
| Regular | Светлые и стандартные поверхности |
| Inverse | Тёмные поверхности: тултип наследует режим фрейма, отдельного варианта нет |

Тултип берёт режим той поверхности, над которой открыт.

## Доступность (A11y)
- Контейнер получает *role="tooltip"* и постоянный `id`;
- Триггер связывается с тултипом через *aria-describedby*, пока тултип открыт;
- Если тултип заменяет отсутствующую подпись (кнопка-иконка), он подключается через *aria-labelledby*: это имя, а не описание. Один и тот же текст не подключают дважды;
- Триггер обязан быть фокусируемым. Неинтерактивный текст оборачивается в элемент с `tabindex="0"`, но чаще правильнее показать текст рядом с элементом;
- Не используйте атрибут `title`: он не открывается по клавиатурному фокусу, не настраивается и по-разному читается screen reader;
- Внутрь тултипа фокус не переводится, интерактивных элементов в нём нет: с клавиатуры до них было бы не добраться;
- WCAG 1.4.13: подсказку можно навести курсором, она закрывается по Escape и не исчезает сама;
- WCAG 2.2.1: автозакрытия по таймеру нет;
- Контраст текста к фону тултипа ≥ 4,5 : 1;
- Тултип не помещают в live-region: он читается как описание триггера;
- Тултип не должен перекрывать содержимое, которое нужно для работы.

## Управление клавиатурой
| **Действие** | **Результат** |
|:--|:--|
| Tab на триггер | Тултип появляется сразу, без задержки |
| Tab / Shift + Tab с триггера | Тултип закрывается |
| Escape | Закрывает тултип, фокус остаётся на триггере |
| Enter / Space на триггере | Выполняет действие триггера, тултип скрывается |
| Внутрь тултипа | Фокус не переводится, своих клавиш у тултипа нет |

## Делать
- Писать одну короткую мысль;
- Открывать тултип и по фокусу, и по наведению;
- Давать задержку закрытия, чтобы курсор можно было перевести на тултип;
- Показывать полный текст там, где он обрезан многоточием;
- Держать один тултип на экране.

## Не делать
- Не класть в тултип ссылки, кнопки и поля;
- Не прятать в тултип обязательные инструкции, требования к паролю, условия (`field.md`, `password-input.md`);
- Не дублировать видимую подпись;
- Не показывать тултип по клику — это Popover;
- Не закрывать тултип по таймеру;
- Не вешать тултип на элемент, который нельзя сфокусировать;
- Не использовать `title` как замену компонента.

## Связанные компоненты
| **Компонент** | **Когда использовать** |
|:--|:--|
| Popover | Нужен интерактив внутри или открытие по клику и на тач |
| Hint | Обучающая подсказка: онбординг, тур по интерфейсу |
| Field | Description — постоянное пояснение к полю |
| Field | Description и Validation Message поля |
| Alert | Сообщение о состоянии блока или формы |
| Banner | Сообщение уровня страницы или раздела |
| Button (icon-only) | Типовой триггер тултипа |
| Status, Badge, Chip | Источники обрезанного текста, который раскрывает тултип |

# Решения для согласования (docs-writer 20.09.2026)
1. **Текст тултипа — `typography/body/small` (12 / 16, 400, LS 25).** Отдельной роли `typography/…/tooltip` на уровне 2 нет. Метрики `body/small` и `helper/default` совпадают, но `helper/*` описан как текст поля, поэтому взят `body/small`. Выбор — за ds-architect.
2. **Максимальная ширина 320 px — закрыто.** ds-architect 20.09.2026 завёл `size/overlay/{width-compact,width,width-wide}` = 240 · 320 · 400; максимальная ширина тултипа — `size/overlay/width`. Отдельный `tooltip-max-width` не нужен, `size/layout/text-max-width` (абзац текста) для оверлея не используется.
3. **Задержки: открытие 300 мс, закрытие 100 мс, по фокусу — без задержки.** В `motion/duration` есть шаги 0 · 75 · 100 · 150 · 200 · 300 · 500, но это длительности анимации, а не задержки. Предлагается `motion/delay/tooltip-open` = 300 и `motion/delay/tooltip-close` = 100; задержка закрытия обязательна по WCAG 1.4.13.
4. **Хвостик опционален и скрывается при сильном сдвиге.** Геометрия закрыта: ds-architect 20.09.2026 завёл `size/overlay/arrow` = 8 и `size/overlay/arrow-depth` = 4, форма одна на все оверлеи, цвет хвостика = цвет поверхности. Требует подтверждения только поведение: при сдвиге, когда хвостик не помещается, он скрывается, а не «уезжает» в угол.
5. **На тач-устройствах тултип не показывается.** Тот же текст открывается по тапу в Popover с триггера-иконки «i».
6. **Инверсный тултип — не вариант компонента**, а режим dark на фрейме. Отдельный тёмный вид (как в Material) потребовал бы токенов, которые противоречат `docs/architecture.md`.
7. **В каталоге Tooltip остаётся `interactive: false`**: у самого тултипа нет состояний наведения и нажатия, они принадлежат триггеру.
8. **Триггер, который недоступен, помечается `aria-disabled="true"`**, если по нему нужна подсказка: у `disabled`-элемента нет ни hover-событий, ни фокуса.
